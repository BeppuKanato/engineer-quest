# 単元最終リザルトの視覚強化（Issue #150）

目的: Issue #150 として、単元完了時の最終リザルトを視覚的に強化する。適用範囲はフロントエンドの最終リザルト表示（`UnitFinalResult`、`FinalLearningRewards`、紙吹雪と単元マップの共通部品）。最終確認日: 2026-11-06。
正本・前提: リザルト画面視覚強化の原案（2026-11-06、ユーザ承認済み。PR1 = #165 / PR #166 の続編）。決定事項は「最終の紙吹雪はフェーズ用より一段強いプリセット」「実績は最終リザルトではコンパクトな要約（アイコン＋題名）に留め、祝う場面はフェーズ区切りに置く」「達成の図は完了グレーではなく達成の青で灯す」。原則として、リザルト画面に赤・❌ の非難表現は置かない（#165 で確定）。

## 実装内容

- 紙吹雪: 共通部品 `front/src/features/learning/app/ResultConfetti.tsx` に `preset` を追加した。`phase`（既定、各 90 片・2 点）は不変。`final` は 3 点（左右＋中央）・各 110 片・spread 90・ticks 320 で一段強い。最終リザルトはマウント時に `preset="final"` で一度だけ撃つ（再描画・ダイアログ開閉で再発射しない、動きを減らす設定では撃たない、は phase と同じ）。
- 全灯ミニマップ: 単元画面の `UnitPathMap` が持っていた波形（WAVE / wavePoint / wavePath）を `front/src/features/learning/app/unitPathGeometry.ts` へ切り出して共通化し、同じ波形で軌跡と全ノードを達成の青（focus）で灯す静的な `UnitPathMiniMap` を追加した。スタート／ゴールの旗も単元画面と揃えた。操作は持たず、ステージの内訳は下のフェーズ別行が担うため装飾として扱う。
- 要約タイル: 見出しの下に、フェーズ別サマリから組み立てるタイルを最大3つ並べる。初回正解（確認問題・応用問題の合算 X / Y 問）、自分で実装のテスト実行回数、ヒント使用（合計回数、0 なら「未使用」）。記録のない項目は出さない。値はすべて既存サマリの事実のみで、新しい記録項目は足していない。
- 実績のコンパクト要約: `AchievementList` に `compact` モードを追加し、最終リザルトでは説明文なしのアイコン＋題名だけにした（表示ログ `achievement_present_view` は従来どおり送る）。フェーズ区切りでの提示が正式な獲得の場面であり、最終リザルトは二重提示を要約に改めた。
- 獲得カードのタイル: これまで最終リザルトに一切出なかった獲得知識カード（`LearningRewards.awardedCards`）を、レアリティの枠色・地色（`knowledgeCardTones`、報酬側の `presentationFor` 経由）を持つタイルで一覧する。見出し文言は `rewardText.finalCards`。
- フェーズ別行（完了チェック＋初回成績の事実文＋復習ボタン）と締めの文、コース一覧への導線は従来どおり。保存・完了判定・報酬キューには触れていない。

## 検証

- `verify:bfs-unit`（拡張）: 最終リザルトが `preset="final"` の紙吹雪、全灯ミニマップ、要約タイルを持つこと、紙吹雪の final プリセット（3点目・各110片）を固定した。
- `verify:unit-overview`（追随）: 波形の正本が `unitPathGeometry` へ移ったことに合わせて、正弦・wavePoint の契約を同モジュールへ向け直した（単元画面の契約自体は不変）。
- `verify:learning-rewards`（拡張）: 最終リザルトの SSR で、実績（コンパクト要約）と獲得カードのタイル・見出しが出ることを固定した。
- 上記を含む全 verify、front の lint・typecheck・build が通過する。

## 確認方法

対象 URL は http://localhost:3000/courses/roadmap/course-algorithm-breadth-first-search-v1/learn （ログインと進捗が必要）。スクリーンショットは環境の都合で未取得のため、見え方はデプロイ後の実機確認に委ねる。

1. BFS 単元を最後まで完了させる。最終リザルトで、フェーズ用より強い紙吹雪（3方向）が出ること、全ノードが青く灯ったミニマップ、要約タイル（初回正解の合算・テスト実行・ヒント）が並ぶことを確認する。
2. 実績がアイコン＋題名だけの compact な行になっていること、獲得した知識カードがレアリティ色の枠のタイルで並ぶことを確認する。
3. フェーズ別行の復習ボタン、締めの文、「コース一覧に戻る」が従来どおり動くことを確認する。
4. 動きを減らす設定で、紙吹雪なし・静止した完成状態になることを確認する。
