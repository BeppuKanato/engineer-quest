# 学習者の目標のホーム接続（Issue #508）

目的: Issue #508 として、学習者が立てた目標（単元ミッションの採用）をホームの再開導線に接続する。適用範囲はフロントエンドのホーム表示と目標状態の共有。最終確認日: 2026-11-25。
正本・前提: [redesign-overview-2026-11.md](redesign-overview-2026-11.md) §2.3、[redesign-ui-policy-2026-11.md](redesign-ui-policy-2026-11.md)。ホームのレイアウトは現行（v37、home-layout-137 の後継形）を維持し、内容源だけを切り替える。

## 実装内容（仕様）

- 目標の状態は1つだけ持つ（新しい目標が古い目標を置き換える）。立てる場所は、コースカードのチップ行右端、単元バンドのチップ行、ストーリーゲートのヘッダーに置いた目標フラグであり、すべて同じ状態を読む。
- ホーム上部の目標帯：旗＋目標文（22/900）＋ゲージ。目標文は採用した単元ミッションを能力形で書く（例：「本を番号順に並べ替える」）。ゲージは「学習ステップの進捗」「{完了} / 7 ステップ完了」とし、塗りは緑（完了した量＝緑の統一）。
- 目標が未設定のとき：学習中の単元があればそのミッションを、なければ次の単元のミッションを、既定の表示として出す（学習者を空白で迎えない）。
- 狙いカード（ポイントするマスコット＋吹き出し＋「次は『段階名』」＋ボタン「学習を再開する」）は、目標の単元の現在地を指す。目標の単元と学習中の単元が異なる場合は、目標の単元を優先し、その旨が分かる文にする。
- 大目標バナー（#367 の表示）はホームから取り除く。大目標のデータや生成の撤去そのものは本 Issue の範囲外（redesign-overview §2.3 の撤去作業として別途扱う）。
- 「目標」という語は学習者側だけに使う。単元の課題そのものは「単元ミッション」と呼ぶ。

## 確認方法

1. コース一覧で目標フラグを立て、ホームの目標帯と狙いカードがその単元を指すことを確認する。フラグを外すと既定表示に戻ることを確認する。
2. 大目標バナーが出ないことを確認する。
3. スクリーンショットは約1093×614と約2560×1440の2サイズを PR に付ける。
