# 復習への接続（Issue #509）

目的: Issue #509 として、単元リザルトの復習候補とデイリーレビューを、実際の復習行動につなげる。適用範囲はフロントエンドの導線と、デイリーレビューの選出。最終確認日: 2026-11-25。
正本・前提: 2026-11-19 の強化計画の決定（復習の設計）、[redesign-ui-policy-2026-11.md](redesign-ui-policy-2026-11.md) §5.4（到達状況アコーディオン）。

## 実装内容（仕様）

### リザルトからの接続

- 単元リザルトの到達状況アコーディオンの各フェーズ行にある「復習する」は、そのフェーズの復習に直接入る入口とする。復習を終えたら単元リザルトへ戻る。
- 復習候補の判定（初回に間違えた問題を含むフェーズ）は、既存の評価記録から行う。表示の規則は Issue #499 の仕様に従う。

### デイリーレビュー

- 1日1問。対象は完了した単元のフェーズ3・5・6の問題。
- 選出の優先順：①初回に間違えた問題、②長く触れていない問題。復習で正解した問題は30日間、選出から外す。
- ホームの復習カードには、その1問が選ばれた理由を出す。
- 復習の回答は、評価エビデンスと概念到達の判定には一切触れない（到達の定義は「最終的に正解」、復習はその外）。

## 確認方法

1. 復習候補のある単元リザルトから、対象フェーズの復習に入って戻れることを確認する。
2. ダミーの学習記録で、選出が優先順どおり（初回ミス優先、復習正解は30日除外）になることを確認する。
3. 復習後に概念到達と評価エビデンスが変わっていないことを確認する。
4. スクリーンショットは約1093×614と約2560×1440の2サイズを PR に付ける。
