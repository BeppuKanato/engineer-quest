# フェーズ4コード表示の横スクロールと単元画面下のグレー帯の修正（Issue #301 / #303）

- 目的: Issue #301（フェーズ4でコードが見切れ、スクロールバーでも末尾を表示できない）と、Issue #303 の「下に灰色の線が見える。これは？」について、原因を特定し欠陥として直せる範囲を修正した記録。
- 適用範囲: 全6単元のフェーズ4コード対応キャンバス（BFS / DFS / バブルソート / 棒倒し法 / 穴掘り法 / 二分探索）と、全5単元の単元プレビュー（DFS は単元コンテナ未実装のため対象外）。
- 最終確認日: 2026-11-08
- 正本・関連: `docs/concept/learning-player-ui.md`（プレイヤー UI 定義）。Issue #303 の「直前の回答」項目は PR #320 で対応済みであり、本記録の対象外。

## 1. Issue #301：フェーズ4のコードが見切れる

### 症状

バブルソートのフェーズ4（動きとコードの対応）で、コードが7行目付近から見切れ、下部の横スクロールバーを使っても表示できない（ユーザー報告・スクリーンショット）。

### 原因

コード対応キャンバスのコード列は全単元で同一構造だった。

- 列の Box は `overflowY: "auto"` のみで、横方向のスクロールを持たない。
- コード表示（`front/src/features/learning/code/CodeDisplay.tsx`）は各行 `whiteSpace: "pre"` で折り返さないため、列幅より長い行は列の外へはみ出す。
- しかし列の親（横並びの全体）には `overflowX: "auto"` があるため、はみ出した分は「全体の横スクロール量」に紛れ、列自身の横スクロールとしては現れない。画面計測でも、スクロールバーのつまみがトラック全幅を占め（＝列の横スクロール量ゼロ）、列の右端より外に文字が描かれていない（切り取られている）ことを確認した。長い行の末尾は原理的に辿れない。

行長は単元ごとに異なり、バブルソート7行目（63文字＋行番号ガター）や棒倒し法の `directions = {...}` 行など、正本コードの最長行は列幅（利用可能幅の48%、最小620px）を上回る。

### 修正

フェーズ5（コードの確認問題）で既に使われている割り付けを、フェーズ4のコード列へ揃えた。

- コード表示だけを `overflowX: "auto"` の外箱で包み、内側に `width: "max-content"`、`minWidth: "100%"` の箱を置く。コード本来の幅がそのまま横スクロール量になる。
- 変数表示（`dl`）はスクロールの外に残し、横スクロールしても変数は固定で見える。
- 縦スクロールは従来どおりコード列全体が担う（内容は要素の中でスクロールし、操作要素は固定、という既存方針に沿う）。

### 単元別の適用

コード列の構造は全6単元で同一（DFS のみ列幅比率 52%）だったため、全単元へ同じ修正を適用した。BFS は `BfsCodeDisplay`（共有 `CodeDisplay` の薄いラッパー）を同じ箱で包んでいる。

## 2. Issue #303：画面下の灰色の帯

### 特定結果

帯の正体はフェーズ6の部品ではなく、**アプリ全体の body 背景**である。

- スクリーンショット3枚をピクセル計測すると、帯の色は一様に `#e5e7eb` で、これは `front/src/app/layout.tsx` の body に付いた Tailwind `bg-gray-200` の色と一致する。
- 帯の上端位置はスクリーンショットごとに異なり（内容量とスクロール位置で変わる）、選択肢ボタンや「自分で実装へ進む」ボタンが帯の上に重なって描かれていた。つまり帯は要素ではなく「白い画面の外側」である。
- 学習画面は `height: 100dvh` の固定高で白背景だが、単元プレビューの内容側は最終結果画面だけ `overflowY: "auto"` で、それ以外ははみ出しを許していた。フェーズ6の内容（図＋選択肢）が画面高を超えると、内容が白い画面の底辺を越えて body のグレー背景の上に描かれ、その境界が「灰色の線／帯」に見えていた。

### 修正

全5単元の単元プレビューで、内容を包む箱を次のように揃えた。

- `overflowY` を最終結果だけでなく全画面種別で `"auto"` にし、画面より高い内容は白い画面の中でスクロールさせる。
- 背景色（`playerTokens.background`）をそのスクロールする箱自身に持たせ、スクロールした先でもグレー背景が覗かないようにする。

`app/layout.tsx` の body 背景自体は他画面の前提（グレー地に白カード）であり、変更していない。
