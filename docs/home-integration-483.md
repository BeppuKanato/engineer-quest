- 目的: ホームから現在地と次の行動が分かり、保存した学習の続きへ戻れるようにする。
- 適用範囲: ホーム画面とホームAPIの表示用集計。研究用のフィードバック生成・実験条件・教材は変更しない。

## 構成

| 順序 | 節 | 表示する内容と空の場合 |
| --- | --- | --- |
| 1 | 現在地 | 公開中の新フロー単元の完了数とカード所持数（現行7単元・21枚）、マスコット、グループ別の全単元リンク。分類は探索／迷路生成／並び替え／最適化で、順序のロックを付けない |
| 2 | 今日の狙い | 最近更新された進行中単元、なければ定義順の未開始単元をおすすめする。実績とカードの近い目標を併記。全要素がなければ節を隠す |
| 3 | 前回の続き | 最近更新された進行中単元の未完了フェーズへ直接戻る。保存済みフィードバックがあれば「次の一歩」を1行で表示。再開先がなければ節を隠す |
| 4 | 今日の復習 | #476のDailyReviewCardをそのまま使用。出題なし・取得中・取得失敗では枠ごと隠す |
| 5 | 学習ストリーク | 日本時間で今週（日曜〜土曜）の学習有無を表示。学習の源は#459と同じ確定記録だけ。未学習でも曜日と0日を表示 |
| 6 | 掲示板の新着質問 | 過去7日以内、公開中・未解決、カテゴリQUESTIONの投稿を新しい順に最大3件。0件なら節を隠す |

画面入口が認証・取得と部品の接続を担当し、HomeDashboardは集約済みデータを表示する。復習と大目標はapp側から表示用の差し込み口へ渡し、独立したfeatureの内部同士を参照しない。

## 集計と再開のルール

- ホーム用に固定0の実績進捗を作らず、既存の `getAchievementsByUser` の値を利用する。未解除・非シークレットで `0 < progress < goal` の実績を達成割合の高い順に最大2件選ぶ。同率なら選択中の目標実績を優先し、その後IDで安定化する。進捗0、解除済み、すでに条件を満たしているものは「あと少し」に含めない。
- 所持カードは公開中の新フロー単元・公開カードに限って数える。単元ごとの残りが1枚で、所持数が0ではない場合にカードの目標を表示する。未所持カードの題名や内容は取得・表示しない。
- 再開する単元は開始日の新しさではなく、UnitLearningProgressとPhaseLearningProgressの更新日時で選ぶ。未完了の保存フェーズを利用し、既存プレイヤーの再開可能範囲を超える場合は最初の未完了フェーズへ戻す。リンクは既存の `/courses/roadmap/:courseId/learn?phase=:phaseKey` を使う。
- フィードバックは本人の生成済みFeedbackV1を生成日時の新しい順に読み、selection.candidatesの先頭（旧形式はselection.nextStep）を利用する。空・不正な記録は表示しない。生成・再評価・実験条件の参照は追加しない。改行は空白に正規化し、1行を超える分は省略表示、全文はtitle属性に保持する。
- 週の各日は、ホストやブラウザーのタイムゾーンではなく日本時間の日付キーで判定する。月・年をまたぐ週でも前月の学習日を失わない。連続日数は#469の評価器と同じcurrentLearningStreakを使い、今日未学習でも昨日までの連続を保つ。
- 大目標は進行中単元がある場合だけ、今日の狙いの下に置く。BigGoalBannerのcurrentOnlyで現在の目標だけを表示し、過去の目標は取得・表示しない。

## 残したもの・外したもの

残したものは、共通ヘッダー、相棒と表示名、全単元への導線、実績の実データ、学習継続と曜日、現在の大目標、復習カードである。おすすめ・再開・近いカード目標・新着質問を判断7の位置へ統合した。

外したものは、冒頭の独立したContinueLearning、最大6件の大きな単元グリッド、独立した目標実績カード、「エンジニア見習い」の固定表示、ストリーク内の追加の相棒と固定の応援文、過去の大目標一覧である。実績の表示名にあるLv.はホームでは「第◯段階」と表示し、ユーザーのEXP・レベル・ランクは表示しない。

旧APIのuser統計・missions・targetAchievement・calendarは互換用に保持するが、今回の画面はoverview・today・resume・week・questionsを使用する。targetAchievementの数値も同じ評価器から取得する。旧calendar.continuationDaysは従来の今日を起点とする値を保持し、画面のストリークにはweek.streakDaysを使う。
