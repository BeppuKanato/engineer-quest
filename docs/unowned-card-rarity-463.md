# 未所持の知識カードのレアリティ表示（D1）

- 目的: 未所持カードの内容を伏せながら、レアリティを獲得予告として示す。
- 適用範囲: 知識カード画面・未所持カード・共通レアリティラベル。バックエンド・並び順・配布方式は対象外。
- 状態: 実装・自動検証・テストデータによる2サイズの表示確認済み。実DB・認証を含むE2Eは未実施。
- 最終確認日: 2026-11-19。
- 正本: [Issue #463](https://github.com/BeppuKanato/engineer-quest/issues/463)、[開発ガイド第10節](../AGENTS.md#10-ゲーミフィケーション強化プログラムの実施基準)。
- 対象実装コミット: `c4d62518`。

## 実装

- `UnknownKnowledgeCard` に rarity を渡し、共通の文字色・背景色・枠色とカタカナラベルを使ったチップを追加。シルエット・「？？？」・非操作要素であることは保持し、題名・説明などは渡さない。
- `knowledgeCardTones` の正本は C2 で移動済みの `front/src/components/rewards/rarity.tokens.ts`。既存の feature 側再exportを保ち、ラベルだけを「コモン／レア／エピック」に変更した。色・レアリティ識別子・動きは変更していない。
- 所持済みカード、実績解除、カード獲得、最終結果も同じトークンを参照するため表記が揃う。知識カード画面の集計ラベルも同じ定義を参照する。
- 所持済みタイルの描画ロジック、`sortKnowledgeCards`、API、seed、配布方式は変更していない。DB適用は不要。

- front `npm run typecheck`、`npm run verify:learning-rewards`、`node scripts/verifyUnlockExperience.cjs`: 成功。
- 報酬表示検証を更新し、3レアリティの色・日本語ラベル、未所持の内容非表示と操作要素なし、実績解除・最終結果の日本語ラベルを確認。並び順の既存回帰検証も成功。
- front 変更した3つのTS/TSXファイルへの個別lint、`npm run build`: 成功。buildは `.next` 作成権限エラー後に制限外で再実行した。既存の単元プレビュー5件の hooks 警告あり。
- `verify:static` は front に存在しないため、back の `npm run verify:static` を実行し成功（`verify:collections` を含む）。バックエンドのコード変更はない。
- `git diff --check`: 成功。
