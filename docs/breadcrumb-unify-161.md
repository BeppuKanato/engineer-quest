# パンくずリストの配置統一（Issue #161）

目的: 画面ごとにずれていたパンくずの配置を、アプリ全体で主要画面の基準（1440px コンテナの左端、ヘッダーからの距離 pt { xs: 3, md: 4 }）に統一する。Issue #161 の棚卸しと方針に従う。最終確認日: 2026-11-06。

## 実装内容

- 対象8画面のパンくずを、内容コンテナの中から切り離し、ヘッダー直下の独立行（`maxWidth: 1440`、`pt: { xs: 3, md: 4 }`）に置き直した：コレクション、掲示板（一覧・新規投稿・投稿詳細）、作る（トップ・課題詳細・実装）、挑戦中・提出済み。
- 内容コンテナの幅は各画面のまま変えていない（コレクション 1200、掲示板一覧 1120、掲示板新規・詳細 960、作るトップ 1180、課題詳細 1120、実装 1440、挑戦中・提出済み 1080）。内容コンテナの上余白はパンくずとの間隔として 24px（pt: 3）に統一し、下余白は従来のまま。
- 主要画面（コース・実績・履歴・知識カード・プロフィール）はもともと 1440 コンテナ（py { xs: 3, md: 4 }）の先頭にパンくずがあり基準を満たすため、変更していない。単元画面は PR #160 で独立行に分離済み。教材内（学習画面）にパンくずを置かない方針も維持する。
- 作る課題詳細では、読み込み中（スケルトン表示中）もパンくず行が出るようになった（パンくず自体は課題名のフォールバック表示を持つため、読み込み状態に依存しない）。

## 検証

- 新規 `verify:app-breadcrumbs`: 独立行にした8画面について、パンくず行が 1440 基準であること、パンくずが行の中にあること、内容コンテナの幅が元のままであることを固定した。主要画面5画面の基準（1440 + py { xs: 3, md: 4 }）もあわせて固定した。
- 上記を含む全 verify（19件）、front の lint・typecheck・build が通過する。

## 確認方法

スクリーンショットは環境の都合で未取得のため、見え方はデプロイ後の実機確認に委ねる。

1. コース画面とコレクション画面を行き来し、パンくずの左端位置とヘッダーからの距離が一致することを確認する（内容の幅はコレクションの方が狭いままでよい）。
2. 掲示板（一覧→新規投稿→投稿詳細）でも同じ位置にパンくずが出ることを確認する。
3. 作る（トップ→課題詳細→実装）と「挑戦中・提出済み」でも同じ位置に出ることを確認する。
4. 学習画面（教材内）にはパンくずが出ないままであることを確認する。
