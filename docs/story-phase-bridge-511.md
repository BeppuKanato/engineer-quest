# ストーリーからフェーズ1への接続文（Issue #511）

目的: Issue #511 として、ミッション提示（ストーリー）の世界からフェーズ1の学習世界への接続を作る。適用範囲は教材のキャプション（バブルソート以外の単元）。最終確認日: 2026-11-25。
正本・前提: [redesign-overview-2026-11.md](redesign-overview-2026-11.md) §6-1、[redesign-ui-policy-2026-11.md](redesign-ui-policy-2026-11.md) §7。バブルソート分は Issue #505 に含まれる。

## 実装内容（仕様）

- 各単元のフェーズ1の最初のキャプションに、ミッション場面へつなぐ半文を入れる。役割は「提示された課題の場面」と「これから学ぶ動きの世界」が同じ話だと、学習者に分かるようにすること。
- 書き方の条件：
  - ストーリーを見ていない学習者にも破綻しない文にする（「さっきの本棚」のような、提示を見た前提の指示語で始めない）。
  - 課題の対象（並べ替える本、届ける荷物など、ミッションと同じ物）に触れてから、フェーズ1の対象へ渡す。
  - 半文に留める。説明を足してフェーズ1の教材本文を膨らませない。
- 各単元のストーリー本文の実装と同時に作業してよい（本 Issue は接続文だけを切り出したもの）。

## 確認方法

1. ストーリーを見た直後にフェーズ1を開き、場面のつながりが読めることを確認する。
2. ストーリーを見ずに（復習や直接入場で）フェーズ1を開き、冒頭の文が破綻しないことを確認する。
3. 対象単元の verify が通ることを確認する。
