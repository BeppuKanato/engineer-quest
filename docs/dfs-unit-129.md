# Issue #129 DFS 単元プレビュー実装記録

- 目的は、DFS の7段階をひとつの単元として学び、開いた段階へ戻って復習できるようにすること。
- 対象は DFS の単元プレビューと BFS・DFS が共有する単元コンテナ。
- 最終確認日 2026-11-10
- 正本は [Issue #129](https://github.com/BeppuKanato/engineer-quest/issues/129)、[DFS 基準データ §0.1](concept/dfs-unit-baseline.md)、[教材指針のブリッジ](concept/learning-materials-guideline.md)。

## 実装

`LearningUnitPreview` は、段階の定義、対応する画面、到達図、完了文言を単元ごとに受け取る。ナビゲーション、完了通知、遷移、ブリッジ、リザルトの配置を BFS と DFS で共有する。BFS のアプリ側が使う初期状態、保存、報酬、フィードバック、学習イベントの受け口は従来どおり使える。

導入・動きの説明・動きとコードの対応は、完了操作から直接ブリッジへ進む。2つの確認問題は単元側で初回の正解数を示してからブリッジへ進む。応用問題は画面内の結果から実装へのブリッジへ進み、実装は全テスト通過後の「単元の結果を見る」で最終結果を開く。ブリッジ文には次に行うことを置き、DFS の確認結果では実際の初回正解数を伝える。

一度開いた段階は保持する。上部ナビゲーションや最終結果から復習するときは、ブリッジを挟まず、再生位置・回答・エディタの状態を引き継ぐ。DFS の非表示のプレイヤーは再生を中断し、戻ると続きから見られる。BFS の単品プレビューは既存の再生設定を引き継ぐ。

コース入口と進捗保存は #130 の対象。単元プレビューの確認に DB の適用は不要。

## 確認方法

front の開発サーバーで [DFS 単元プレビュー](http://localhost:3000/learning-preview/dfs-unit) を開く。

1. 導入の最後で「動きの説明へ進む」を押す。動きの説明とコード対応は最後のコマから次の段階へ進む。
2. 2つの確認問題は回答後に初回正解数を確認する。応用問題では画面内の結果から「自分で実装へ進む」を押す。
3. `dfs_order` のテスト5件を通し、「単元の結果を見る」を押す。各段階の結果と復習ボタンを確認する。
4. 上部ナビゲーションまたは復習ボタンから開いた段階へ戻る。

`npm run verify:dfs-unit` は、実際のコンテナのコールバックを使って全7段階の進行、ブリッジ、結果、復習と BFS の途中再開を検証する。
