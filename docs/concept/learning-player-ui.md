# 学習プレイヤーUI定義

- 目的: 新学習フローの教材プレイヤーについて、画面構成、色、操作系、アニメーションの実装上の定義を定める。
- 適用範囲: 学習プレイヤー本体と、その単品プレビューページ。アプリ本体の画面（ヘッダー、コース画面等）のデザインは対象外。
- 最終確認日: 2026-11-04
- 関連文書: 教材の中身の規則は [learning-materials-guideline.md](learning-materials-guideline.md)（教材指針全文）、確定事項の要約は [learning-materials-v2.md](learning-materials-v2.md)。この文書はプレイヤー UI の実装定義の正本であり、教材指針とは分担が異なる。
- 経緯: Issue #68 の実装（PR #80）では、教材指針に具体的な配色と操作配置の指定がなかったため、暫定の色トークンと操作レイアウトが置かれた。この文書でその暫定値を置き換える。

## 1. 画面構成と占有率

- プレイヤーは、表示領域の大半を教材のために使う。単品ページでは、教材領域（キャンバス＋キャプション＋操作バー）がビューポートの **7割以上** を占めることを目安とする。
- 固定の小さい最大幅（例: 880px）でカード状に中央寄せし、周囲に大きな余白を残す見せ方をしない。幅は表示領域に追従させ、キャンバスの高さも残りの領域を活かす。
- プレイヤー外側の余白と内側のパディングは最小限に留める（目安: 16px 以下）。背景色や影で教材を「浮かせる」装飾をしない。
- アプリへ組み込んだ状態でも、ヘッダー等のアプリ側要素を除いた残り領域の大半を教材が使う。組み込み側の都合で教材を縮小しない。

## 2. 色の定義

状態と色の対応は、確定済みの教材サンプル（指針のフェーズ1・2の見本）で使われている意味付けで固定する。実装側が別の対応を発明しない。

### 2.1 状態と色の対応

| 状態 | 意味 | 塗り | 枠 |
| --- | --- | --- | --- |
| 処理中 | 今まさに処理している要素 | 青 `#2563eb` | 青 `#1d4ed8` |
| キュー待ち | データ構造の中に保持されている要素 | ベージュ `#f5e7c1` | `#c9a227` |
| 完了 | 処理が終わった要素 | グレー `#e5e7eb` | `#9ca3af` |
| 未処理 | まだ処理されていない要素 | 白 `#ffffff` | `#9ca3af` |
| 層・段階 | 距離の層などの帯 | グレー系 `#f3f4f6` / `#e5e7eb` の交互 | なし |

- 強調（今見るべき要素のハイライト）は、処理中の青を使った太枠または破線枠で表す。強調専用の新しい色を増やさない。
- 層・段階の表現に、紫・ピンク等の装飾的なパステル色帯を使わない。層はグレースケールで表す。
- この対応はプレイヤー内に閉じる。アプリ本体の色の意味（青＝必須・次、緑＝完了、橙＝挑戦 等）を持ち込まない。特に「完了＝緑」は教材内では使わない。

### 2.2 テキストの色

- 情報を伝えるテキストは、**黒 `#111827` を基本**とする。対象はキャプション、ノード名、距離・層のラベル（例: 「0歩」）、データ構造の要素名、変数の表示のすべて。
- 状態をテキストの色で表さない。テキストを淡い色にして背景に溶かす表現をしない。
- 例外は、青い「処理中」要素の上に乗る文字だけで、白 `#ffffff` を使ってよい。
- 状態の区別は色を主とし、記号やラベルは補助に留める。全要素に状態テキストを常時表示するようなノイズを増やさない（教材指針の「無駄なメタ指示・UIノイズの排除」に従う）。

## 3. 操作系の配置

プレイヤーバーの配置は、一般的なメディアプレイヤーの並びに固定する。左から右へ:

```
[再生 / 一時停止] [前へ] [次へ] ─── スライダー（伸縮） ─── [ n / N ]
```

- 再生ボタンはバーの **左端** に置く。前へ・次へは再生ボタンの右に並べ、スライダーで分断しない。
- アイコンは一般的なメディア操作のものを使う（再生、一時停止、前へ、次へ）。最終ステップで再生を押した場合は先頭から再生し、その旨が分かる見た目にする。
- キーボード操作: `←` / `→` で前後移動、`Home` / `End` で先頭・末尾へ移動できること（PR #80 の実装を定義として採用）。

## 4. アニメーション

- ステップ間の変化は、瞬時の表示切り替えにしない。変化した要素（例: キューからの取り出し、キューへの追加、強調の移動）をアニメーションで繋ぎ、学習者の視線を変化点へ誘導する。
- 1回の遷移のアニメーションは 200〜400ms 程度を目安とする。自動再生の間隔は、アニメーションが完了する長さを確保する。
- 状態の色変化だけに頼らず、要素の移動・出現を伴わせる。

## 5. 適用

- プレイヤーの色トークン、レイアウト、操作配置はこの文書に従う。PR #80 で置かれた暫定トークン（処理中＝琥珀、キュー待ち＝青、完了＝緑、層＝パステル）と操作レイアウト（[前へ] [再生] スライダー [次へ]）は、この文書の定義で置き換える。
- この文書と教材指針全文が矛盾する場合は、AGENTS.md の優先順位に従い、勝手に片方を選ばず PR で明示する。
