- 目的: BFS 教材フェーズ1「動機づけ」のコンテンツ（全15コマのキャプションと画面状態）を、実装が参照できる形で定める。
- 適用範囲: Issue #69 のフェーズ1コンテンツデータの制作。画面と再生の仕様は [learning-player-ui.md](learning-player-ui.md)、教材の設計規則は [learning-materials-guideline.md](learning-materials-guideline.md) に従う。
- 最終確認日: 2026-11-04
- 取り込み元: Google Drive「フェーズ：動機づけ」（システム修正方針フォルダ）
  https://docs.google.com/presentation/d/1XHHZ4nVYWx_zcXX0x87uUcfahQzGw8Hf5Pk2WpI_sZk/edit
  スライドはモック画面の画像で構成されておりテキスト抽出ができないため、全15コマを目視で書き起こした。キャプションは原文の通り。画面状態の記述と食い違う場合は、キャプションと本書の「不変条件」を優先し、PR で明示すること。

## 全体構成

- 格子状の迷路（グレーのマス＝壁、白いマス＝通路）で「最少手数でゴールに着く」問いを解く場面列（コマ1〜11）。
- 同じ考え方が使える具体場面を、フェーズ2と同じ A〜F のグラフ配置で示す（コマ12〜13）。
- 格子に戻って考え方を言語化し（コマ14）、最終コマで初めて「幅優先探索」と名付けてフェーズ2へのボタンを出す（コマ15）。

### 不変条件（再現時に必ず守ること）

- 最初のゴールは、直進すれば **3手**、迂回路は **5手**。キャラクターは3手の道を選んで進む。
- ゴールが移った後も、新しいゴールへの最少は **3手**。
- コマ12・13のグラフは、フェーズ2で使う A〜F グラフと同じ配置・同じつながり（辺: A-B、A-C、B-D、B-E、C-E、D-F、E-F)。最少ルートはどちらも A→B→D→F の3ステップ。
- 「幅優先探索」という語はコマ15まで出さない。
- 距離の数え方は場面ごとに統一する: 格子では「手数」、駅では「区間数」、SNS では「つながり数」。「○歩」はコマ15で初めて使う。

## 備考

- 迷路の壁の正確な配置はサンプル画像に倣うが、不変条件（手数と場面の順序）を満たす等価な配置でもよい。配置を変えた場合は PR に理由を書く。
- コマ15のボタンがフェーズ1の出口（意思確認の区切り）。フェーズ2への実際の遷移は接続の Issue で扱う。
- 用語対応表（#69 の成果物）を作る際は、本書の数え方（手数／区間数／つながり数／歩）と初出コマを反映する。
