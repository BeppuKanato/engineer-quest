## 1. アルゴリズムの確定事項

棒倒し法（壁伸ばし法）:

1. 盤面は一辺が奇数の正方形グリッド。外周をすべて壁にする。
2. 内側に、2マスおき（座標が両方とも偶数の位置）に柱（壁）を立てる。
3. 柱を左上から右下へ順に処理し、各柱から許される方向のうち1方向へ、隣のマスまで壁を伸ばす。
   - 一番上の段の柱: 上・下・左・右の4方向。
   - それ以外の柱: 下・左・右の3方向（上に伸ばすと輪＝ループができ得るため）。
4. 実際のゲームでは方向は乱数で選ぶ。既に壁になっているマスが選ばれたら選び直す。

主教材は 9×9（柱9本、伸ばす壁9本）。転移・応用の確認には 7×7（柱4本）を使う。

### 主教材（9×9）の検証済みトレース

柱の処理順と選ばれた方向（方向は「許される方向リストへの番号」で表す。フェーズ7の契約と一致）:

|---|---|---|---|---|---|
| 1 | (2, 2) | 上下左右 | 3 | 右 | (3, 2) |
| 2 | (4, 2) | 上下左右 | 1 | 下 | (4, 3) |
| 3 | (6, 2) | 上下左右 | 2 | 左 | (5, 2) |
| 4 | (2, 4) | 下左右 | 0 | 下 | (2, 5) |
| 5 | (4, 4) | 下左右 | 2 | 右 | (5, 4) |
| 6 | (6, 4) | 下左右 | 0 | 下 | (6, 5) |
| 7 | (2, 6) | 下左右 | 2 | 右 | (3, 6) |
| 8 | (4, 6) | 下左右 | 2 | 右 | (5, 6) |
| 9 | (6, 6) | 下左右 | 0 | 下 | (6, 7) |

## 2. 参照コード（契約）

契約ID: `wall-extension-v1`。乱数は関数の外（choices）から与える決定論的な中核を実装対象とする。「既に壁なら選び直す」は乱数側の約束としてフェーズ1・2の説明で扱い、コードの契約には含めない（要判断ポイント参照）。

```python
def generate_maze(size, choices):
    grid = [[0] * size for _ in range(size)]
    for i in range(size):
        grid[0][i] = 1
        grid[size - 1][i] = 1
        grid[i][0] = 1
        grid[i][size - 1] = 1
    pillars = []
    for y in range(2, size - 1, 2):
        for x in range(2, size - 1, 2):
            grid[y][x] = 1
            pillars.append((x, y))
    directions = {"up": (0, -1), "down": (0, 1), "left": (-1, 0), "right": (1, 0)}
    for (x, y), choice in zip(pillars, choices):
        if y == 2:
            allowed = ["up", "down", "left", "right"]
        else:
            allowed = ["down", "left", "right"]
        dx, dy = directions[allowed[choice]]
        grid[y + dy][x + dx] = 1
    return grid
```

戻り値は grid（0=通路、1=壁の2次元リスト）。

## 3. フェーズ別設計

### フェーズ1 導入

- 動機づけ: ゲームの迷路を毎回手で作ることはできない。「コンピュータに迷路を作らせる」必要性から入る（ARCS / 期待価値の型は BFS と同じ）。
- 完成した迷路の盤面を見せ、スタートからゴールまでたどれることを確認する体験を置く。用語（棒倒し法など）はまだ出さない。

### フェーズ2 動きの説明（13ステップ）

1. 9×9の空の盤面を用意する。
2. 外側を壁で囲む。
3. 2マスおきに柱を立てる（9本）。
4. 〜12. 柱を順に処理し、1方向へ壁を伸ばす（表の9件）。キャプションは「一番上の段の左の柱から、右へ壁を伸ばします」のように位置＋方向で一文。
   - 4件目（最初の下段の柱）のキャプションで「上の段以外の柱は、上には伸ばしません」と規則に触れる。
13. 完成。「どのマスからどのマスへも必ずたどり着ける」ことを示す。

### フェーズ3 動きの確認問題（連結2問）

場面: 主教材の途中（4本目まで伸ばした状態）。
- Q1（処理対象の特定）: 次に処理する柱はどれか（グリッドをタップ）。正解は柱 (4, 4)。
- Q2（直後の変化）: 方向の指示（右）が示される。壁になるマスはどれか（タップ）。正解は (5, 4)。

### フェーズ4 動きとコードの対応

フェーズ2と同じトレースを、参照コードの行ハイライトと同期して再生する。対応づけの要点: 柱の二重ループ（2マスおき）、`y == 2` の条件で許される方向が変わること、方向→移動量の対応表、壁の書き込み行。

### フェーズ5 コードの確認問題（独立2問）

- Q1: 柱を立てるループの進み幅。`range(2, size - 1, □)` の □ は 2（選択肢はいずれも文法的に正しい数値）。
- Q2: 方向の対応表の「上」の移動量。`"up": (0, □)` の □ は -1。

### フェーズ6 応用問題（4問）

- Q1（転移・タップ）: 7×7 の途中の盤面で、示された柱と方向から壁になるマスを選ぶ。
- Q2（転移・選択）: 完成した迷路の性質として正しいものを選ぶ（すべての通路がつながっている／輪ができていない、等）。
- Q3（推論可能なエッジケース・選択）: 一番上の段以外の柱が上に伸ばせない理由（上に伸ばすと輪ができることがある）。復習先はフェーズ4の `y == 2` 条件のステップ。
- Q4（Parsons）: 参照コードの行を並び替える（インデント提示あり、余分な行なし）。

- テスト:

  - 表示用 D2: 7×7（choices は §1）。
  - 判定用 J1: 9×9、choices を変えた完全一致。
