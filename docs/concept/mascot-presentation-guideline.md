# マスコット提示ガイドライン

- 目的: 相棒マスコットの表示について、サイズ・接地処理・配置場面・表情の使い分けの指標を定め、画面ごとに場当たり的な表示にならないようにする。
- 適用範囲: アプリ本体の画面におけるマスコット表示すべて。学習導線（単元画面・学習画面・教材内）にはマスコットを置かないことが別途決定済みであり（Issue #132）、本ガイドラインは学習導線の外に適用する。
- 前提（2026-11-06 決定）: 現在のイラスト調の絵柄は前提として受け入れ、描き直しはしない。調和は提示方法（本ガイドライン）で担保する。
- 根拠資料: 使用実態の棚卸し（Drive「2026-11-06_マスコット使用実態-棚卸し」）。本ガイドラインの数値と移行メモは棚卸しの実測に基づく。
- 状態: 正本。最終確認日: 2026-11-06。
- 関連: [アプリ UI/UX 方針](app-ui-ux-guideline.md)（§2 進捗表示、§5 演出の原則）、[プレイヤー UI 定義](learning-player-ui.md)（学習導線内はこちらが正本で、マスコットは置かない）。

## 1. サイズ

役割ごとに4段階を定める。個別画面で任意のサイズを新しく作らない。

| 段階 | 基準 | 許容幅 | 役割 |
| --- | --- | --- | --- |
| S（アイコン） | 40px | 36〜48px | ヘッダーのユーザーアイコン等、識別が目的の表示 |
| M（話者） | 80px | 72〜88px | ヒントや案内の話者、待ち画面の案内役 |
| L（主役） | 160px | 150〜190px | ホームの主表示、ランディングページ、プロフィールの確定表示 |
| XL（プレビュー） | 240px | 220〜300px | プロフィールのキャラ選択画面でのみ使う拡大表示 |

- 同じ画面内で、脇役の表示が主役より大きくならないこと（棚卸しではホーム主表示 132px よりプロフィール脇表示 150px が大きい逆転があった）。
- レスポンシブで段階をまたぐ場合は、段階の基準値同士で切り替える（例: L は xs で 150px、md で 190px）。

## 2. 切り抜き

- 原則は contain（全身を表示する）。
- cover は使わない。全身イラストを cover で切ると頭部や足が欠け、場面ごとに違う切り取られ方になる。
- 円形に収める場合は、顔用に用意されている face の画像を使う。normal や happy を円形に切り抜かない。

## 3. 接地処理

透明背景の画像を無地の上にそのまま置く「素置き」はしない。次のいずれかで「置かれている」状態にする。

| 処理 | 内容 | 向く場面 |
| --- | --- | --- |
| 台座円 | アプリの色トークンに基づく淡色の円（または楕円）を背後に敷く | 常駐表示（ホーム、ヒント）の標準 |
| 足元影 | 足元に薄い楕円の影を敷く | 台座が重くなるカード内・オーバーレイ内 |
| 額縁 | Avatar やカードなど、入れ物自体が枠になる場合は追加処理をしない | ヘッダーアイコン、選択カード |

- 実装は共通のマスコット表示コンポーネント（サイズ段階と接地処理を props で選ぶラッパー）で担保し、各画面の sx で個別に指定しない。
- 接地処理は「浮いて見える」「貼ったように見える」ことへの対策であり、絵柄そのものの様式差を消すものではない。

## 4. 配置場面

### 置く場面

- ヘッダー（S、ユーザーアイコンとして）
- ホーム（L の主表示、S/M の補助表示）
- 「作る」のヒント（M、話者として）
- 待ち画面のオーバーレイ（M、案内役。画面遷移・処理中の2種）
- プロフィール（選択と表示。XL/L/S を段階どおりに）
- ランディングページ（L。未ログインのためキャラはレッサーパンダ固定でよい）

### 置かない場面

- 学習導線（単元画面・学習画面・教材内。Issue #132 の決定）
- 実務画面（フォーム、設定、ログイン等）での装飾目的の使用
- エラー表示（静かに正確に伝える場面であり、UI/UX 方針 §5 の祝福の対象外とも一致する）

### 保留

- 祝福シーン（知識カード獲得、実績獲得、単元完了リザルト）への celebrate の使用は、本ガイドラインでは未確定とする。単元完了リザルトが「学習導線」に含まれるかの線引き（Issue #132 の決定との関係）を含め、使う場合は本節を改訂してから実装する。

## 5. 表情の使い分け

| 表情 | 用途 | 現在の使用 |
| --- | --- | --- |
| normal | 常駐、アイコン、プロフィール等の日常表示 | ヘッダー、ホーム、プロフィール |
| face | 円形クロップ専用（選択カード、S の円形表示） | プロフィール選択カード |
| cheer | 応援、ヒント、紹介などの前向きな促し | ヒント、ランディングページ、処理中オーバーレイ |
| thinking | 待ち、考え中であることの案内 | 遷移オーバーレイ |
| happy | 小さな達成や目標に近い場面の控えめな喜び | ホームの目標実績カード |
| celebrate | 祝福シーン専用（§4 の保留が解けてから） | 未使用 |
| surprise | 当面は使わない。使用場面を定義する場合に本表を改訂する | 未使用 |

- 1つの表示箇所で表情を場面と無関係に差し替えない。表情の指定はコンポーネントの既定に寄せ、呼び出し側での指定は「遷移＝thinking」のような意味のある場合に限る。
- surprise の画像ファイル名が suprise である点はコード側で吸収済みであり、ファイル名は変更しない。

## 6. 動き

- 常駐箇所では静止を原則とする。登場時に1回だけの小さな動き（フェイド、1回だけのバウンス）は可とする。
- 無限に繰り返す動きは、待ち画面のオーバーレイに限る（現行のバウンス 1200ms ループが該当）。
- prefers-reduced-motion ではすべてのマスコットの動きを止める（現行オーバーレイの実装に合わせる）。

## 7. 現行からの移行メモ

棚卸しで確認した不適合と、本ガイドラインへの当て方。適用は画面を触る機会に段階的に行い、一斉移行はしない。

- サイズの無段階な分布（38〜300px の10段階以上）→ §1 の4段階へ寄せる。ホーム主表示 132px は L へ。
- ホームの cover 使用2箇所（132px 主表示、54px 円形）→ §2 により contain 化、円形は face へ。
- ヘッダー Avatar の normal 円形クロップ → face へ（S の円形表示）。
- 素置きの箇所（ヒント、プロフィール各表示）→ §3 の台座円または足元影を付ける。
- celebrate / surprise の未使用 → §5 のとおり当面は据え置き。celebrate は §4 の保留と連動する。
