# DFS「導入」の単品プレビュー（Issue #121）

- 目的: 深さ優先探索の「場所が分からない宝を漏れなく探す」という導入を、迷路からグラフ・実用例へつながる場面列として提示する。
- 適用範囲: DFSの導入データ・描画・単品ページ・verify。状態: 実装記録。最終確認日: 2026-11-06。
- 正本: [Issue #121](https://github.com/BeppuKanato/engineer-quest/issues/121)、[DFS基準データ §0.1・3](concept/dfs-unit-baseline.md)、[教材指針](concept/learning-materials-guideline.md)、[プレイヤーUI定義](concept/learning-player-ui.md)。
- 起点: 最新develop `e88cf3deea3c6d12dde1d9a5982950f2d25f0365`、専用ブランチ`feat/dfs-motivation-121`。共通描画の抽出とDFS導入を別コミットに分けた。

## 実装

- `front/src/features/learning/dfs/motivation/`に完全スナップショット型の18場面を追加した。共通`LearningPlayer`が再生・停止・前後・Home/End・シークを担当し、導入側は描画だけを渡す。再生間隔は3500ms、移動1区間は600ms、動きを減らす設定では移動を省く。
- 迷路の歩行とグラフでの再演は、ともにA→B→D→F→E→C。グラフの2区間を含む場面でも、現在地のキーフレームに中継点を含めてたどる。宝はCへ到着する場面8で初めて描画し、逆送りすると隠れる。
- BFSの`bfsGraph.ts`にあるノード・座標・辺・順序を参照同一で使う。既存の格子配置も`bfsMaze`へ移し、BFS・DFSで共用する。DFS側にグラフや格子の定義は複製していない。
- `player/MotivationDrawing.tsx`へ、BFSの格子・論理座標計算・現在地・道筋の描画を抽出した。BFSも同じ部品を使う。グラフのノード・辺・等倍比のSVGは既存の`GraphDrawing`／`graphGeometry`を使う。
- 調べた場所はグレー、現在地は青、まだ調べていない場所は白。DFSに距離層は付けない。宝箱の装飾には既存のベージュを使い、学習の状態色や緑の完了色を新設していない。
- 場面10で迷路のまま名前を付け、11で「場所（ノード）」「つながり（辺）」を同じ具体的な図に示し、12でグラフへ切り替える。16はグラフのスナップショットを保持する予告、17はフォルダの入れ子の図、18はAからBへの入口と名称の提示。
- 単品の教材領域は84vw×84dvh。利用者向けの段階名は「導入」で、「フェーズ」という文字列は表示しない。
- 最終場面の「動きの説明へ進む」は共通`PhaseNextButton`で表示するが未接続のためdisabled。単品は再生し直して完結できる。アプリ登録、他ステージ接続、進捗・ログ保存、DB・seed・依存関係の変更はなく、DB適用は不要。

## 指針・案との相違と留保

1. 教材指針の導入は4〜5コマを目安としているが、本件の明示指示と基準データ§3の18場面を採用した。
2. 基準案の場面6・18のキャプションは2文のため、各1文へ整えた。場面6は「いちばん奥」を「道の奥」とし、Fに未訪問のEへのつながりがある図で、Fを探索全体の終端と誤認させない文にした。名称と入口の意味は保持している。
3. 基準案§3.3の留保を保持した。往路の順序を実行順と一致させるため、戻る考え方は場面9の軌跡と矢印で示す。途中で別の分岐へ戻る歩行を追加する構成への変更は設計レビュー事項である。
4. 共通指針ではテーマ変更前の専用クッションを求めている一方、基準案は17「フォルダ」から18「グラフの入口＋名称」へ戻る専用コマを持たない。本実装は指定された18場面列を維持しており、この境目を独立したクッションへ分割するなら基準データの場面列を改訂する必要がある。PRにもこの不一致を明示する。
5. 基準案の終了文言「深さ優先探索の働きを見る」は、最新の共通ステージ名・遷移ボタン規則に合わせて「動きの説明へ進む」にそろえた。遷移自体は対象外のままである。

## 確認方法

`front`で`npm run dev`を実行し、**http://localhost:3000/learning-preview/dfs-motivation** を開く。ログイン・DB・バックエンドは不要。

1. 再生または次のステップで18場面を通す。←／→、Home／End、スライダーでも移動できる。
2. 1場面目では宝を隠し、2でA⇄B、3で奥へ進む道の予告を示す。4〜8でA→B→D→F→E→Cをたどり、8で宝を発見する。7へ戻すと宝が消える。
3. 9で来た道、10〜11で名前と用語の橋渡し、12〜15でグラフ上の同じ順序を確認する。
4. 16の予告ではグラフを保ち、17でフォルダの入れ子を示す。18で初めて深さ優先探索と名付け、A→Bの入口とdisabledの次へボタンを表示する。
5. 最終場面から「最初から再生」で再開でき、未接続のボタンから別ページへ移らないことを確認する。

本番ビルドでの起動例: `node node_modules/next/dist/bin/next start --hostname 127.0.0.1 --port 3121`。この場合のURLは http://127.0.0.1:3121/learning-preview/dfs-motivation 。
