# 目標実績のホーム表示（Issue #183）

目的: 実績ページで「目標に設定」した実績の進捗を、ホームでも見られるようにする。最終確認日: 2026-11-06。

## 調査結果

- ホームAPI（`GET /home`）は既に `targetAchievement` を返していた。内容は、未取得の目標実績について「タイトル／要素（factor）ごとの進捗と目標値／行動リンク（href・actionLabel）」。フロントは受け取っているのに表示していなかった。
- そのため本 Issue はAPIの追加なし、フロントの表示追加だけで完結する。

## 実装

- ホーム左カラム（プロフィール／ランク／学習ストリークのカード列）の末尾に「目標の実績」カードを追加した。
  - 実績タイトル、要素ごとの進捗（数値とバー）を表示する。バーの体裁は EXP バーに合わせた。
  - 行動リンクがある場合はボタンとして出す。
  - 目標が未設定のとき、または対象実績が取得済みになったときは、カード自体を出さない（API が null を返す）。
- レイアウト（2カラム構成・カードの見た目）は PR #163 のホーム構成を変えていない。

## 検証

- `verify:home-layout` に、目標実績カードの表示条件と進捗表示を固定した。
- 全 verify・front の lint・typecheck・build が通過する。

## 確認方法

スクリーンショットは環境の都合で未取得のため、見え方はデプロイ後の実機確認に委ねる。

1. 実績ページで任意の実績を目標に設定し、ホーム左カラムに「目標の実績」カードと進捗バーが出ることを確認する。
2. 目標を外すとカードが消えることを確認する。
