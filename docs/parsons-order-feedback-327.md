# Parsons の相対順序フィードバック（Issue #327）

目的: 応用問題の Parsons 問題で間違えたときに「どこを直せばいいか」が分かるよう、動かさなくてよい行を示す。判定方式はユーザーが 2026-11-09 に承認した相対順序方式。
最終確認日: 2026-11-09

## 決定と理由

- 回答後に、正しい位置にある行ではなく「動かさなくてよい行」を示す。
- 判定は絶対位置ではなく相対順序で行う。絶対位置で照合すると、1行を先頭へ動かしただけで位置がずれた全行が間違い扱いになる。実際にはずれているのは動かした1行だけであり、学習者に誤った手がかりを与える。
- 間違っている行には印を付けない（赤・×などの非難表現は使わない、という結果画面の原則に合わせる）。示すのは「この行は動かさなくて大丈夫」という肯定的な情報だけ。

## 判定方法（parsonsOrderFeedback.ts）

- 純粋関数 `parsonsKeepLineIds(learnerOrder, solutionOrder, interchangeableGroups?)` が、動かさなくてよい行の集合を返す。
- 正解順への対応づけ（solution index の列）について、最長増加部分列（LIS）を求め、その部分列に含まれる行を「残せる行」とする。
- 同点の最長部分列が複数ある場合（隣接交換など）は、学習者の現在の並びで前にある行を優先して残す（残す行の位置列が辞書順に最小の最長部分列を貪欲に構成する）。隣り合う2行の入れ替わりでは、後ろにある行だけが「動かす行」になる。
- 入れ替え可能グループ（`interchangeableLineGroups`、BFS と棒倒し法が定義）は assessment の判定（`normalizeParsonsOrder`）とまったく同じ方法で先に正規化する。グループの行が連続ブロックを占めている場合だけブロック内を正解順に直すため、判定側で正解になる並びを「動かす行あり」と示すことはない。
- 正解に含まれない行（ディストラクタ）は決して残す対象にしない（現行コンテンツにディストラクタはないが、関数は安全側に倒してある）。

## 表示（ParsonsBoard）

- `ParsonsBoard` に任意プロパティ `orderFeedback: { solutionLineIds, interchangeableLineGroups?, active }` を追加した。未指定の利用箇所は従来表示のまま（後述の対象外を含む）。
- 印を出す条件は「active（その問題に1回以上回答した）」かつ「現在の並びがまだ正解でない」ときだけ。並び替えるたびに再計算するので、正解の並びに到達した時点で印と凡例は消える。回答前は印を出さない。
- 残せる行には、行の右端にフォーカス青（`playerTokens.focus`）の「✓」と、左端の青いバーを出す（色だけに依存しないよう形の手がかりを併用）。間違っている行には何も付けない。行ピッチ 46px と `scrollable` の契約（PR #320）は変更していない。
- 凡例は1行だけ、盤面とボタン行の間に表示する: 「✓ が付いた行は、動かさなくて大丈夫です」。
- 読み上げ向けに、残せる行には画面外テキスト「この行は動かさなくて大丈夫です」も付けた。

## 接続（全5単元）

- BFS／バブルソート／棒倒し法／穴掘り法／二分探索の応用問題プレビューが、`ParsonsBoard` へ `orderFeedback`（正解順・入れ替え可能グループ・その問題の試行回数 > 0）を渡す。
- 各単元の consolidation 検証に、この接続をソースで確認する assertion を追加した。

## 対象外

- フェーズ7ヒント（レベル4）の練習盤面は採点対象でない練習のため対象外とし、`orderFeedback` を渡していない。従来表示のまま。
