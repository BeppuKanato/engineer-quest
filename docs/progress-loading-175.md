# 「進捗を読み込んでいます。」の表示改善（Issue #175）

目的: 学習画面（LearningScreen）と単元画面（UnitOverview）で、読み込み中が素のテキスト1行だけで「ここだけ適当」に見える問題を直す。最終確認日: 2026-11-06。

## 実装内容

- 共通コンポーネント `ProgressLoadingSkeleton`（`features/learning/app/`）を新設し、両画面の読み込み中表示を置き換えた。
  - 学習画面（screen）: 見出し相当の帯＋ステージのチップ列（7つ）＋教材面の大きな面、という読み込み後の形に近いスケルトン。
  - 単元画面（overview）: 説明文の行＋進捗バー＋ロードマップの枠（角丸24px・高さ460）のスケルトン。
- 読み上げ用の `role="status"` と「進捗を読み込んでいます。」の文言は、画面外テキストとして維持した。
- 読み込み完了後に大きくレイアウトが跳ねないよう、スケルトンは実際の画面要素の高さ・形に合わせてある。

## 検証

- `verify:learning-screens` に、両画面がスケルトンを使うこと・素のテキスト表示が残っていないこと・スケルトンが status ロールを保つことを固定した。
- 全 verify・front の lint・typecheck・build が通過する。

## 確認方法

スクリーンショットは環境の都合で未取得のため、見え方はデプロイ後の実機確認に委ねる。

1. 単元画面を開き、読み込み中に説明文・進捗バー・ロードマップ枠のスケルトンが出て、完了後に大きく跳ねないことを確認する。
2. 学習画面（単元を開いた直後）でも、チップ列と教材面のスケルトンが出ることを確認する。
