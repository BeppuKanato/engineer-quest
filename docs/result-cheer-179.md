# 紙吹雪への歓声の追加（Issue #179）

目的: リザルト画面の紙吹雪に歓声を付け、祝福の勾配（フェーズ結果＜単元最終）を音でも表す。最終確認日: 2026-11-06。

## 音源

- 効果音ラボの「歓声と拍手1 大盛り上がり」「歓声と拍手2 中盛り上がり」（声素材・人々カテゴリ）。利用規約：商用利用無料、クレジット表記不要、改変・形式変換可。
- 既存の効果音ライブラリに合わせて MP3 から Ogg Vorbis へ変換し、`front/public/audio/se/cheer-large.ogg`（約4.1秒）／`cheer-medium.ogg`（約3.4秒）として配置した。

## 割り当て（賞賛の勾配）

- フェーズ結果の紙吹雪（プリセット phase）＝ 中（`resultCheer`、音量 0.5）
- 単元最終リザルトの紙吹雪（プリセット final）＝ 大（`resultCheerLarge`、音量 0.55）

## 実装

- `soundFeedback` の設定に2音を登録し、アプリ全体のサウンド有効／マスター音量の設定に従わせた（設定でオフにすれば歓声も鳴らない）。
- 再生は紙吹雪の共通部品 `ResultConfetti` の発射と同時に行う。紙吹雪が出る場面すべて（フェーズ結果・フェーズ6結果・フェーズ7全通過・単元最終）に一括で付く。
- 動きを減らす設定では、紙吹雪と一緒に歓声も止まる（祝福は視覚と音でひとつのまとまりとして扱う。紙吹雪なしで歓声だけが鳴る状態は作らない）。

## 検証

- `verify:bfs-unit` に、プリセットごとの歓声の再生とサウンド設定への登録を固定した。
- 全 verify・front の lint・typecheck・build が通過する。

## 確認方法

スクリーンショットは環境の都合で未取得のため、見え方・聞こえ方はデプロイ後の実機確認に委ねる。

1. フェーズ結果で紙吹雪と同時に中くらいの歓声が鳴ること。単元最終リザルトでは一段大きな歓声になること。
2. サウンド設定をオフにすると歓声も鳴らないこと。
