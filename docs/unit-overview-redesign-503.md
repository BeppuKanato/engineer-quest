# 単元画面の確定形への刷新（Issue #503）

目的: Issue #503 として、単元画面を設計確定形（2026-11-23 確定）に刷新する。適用範囲はフロントエンドの提示層。最終確認日: 2026-11-23。
正本・前提: [redesign-ui-policy-2026-11.md](redesign-ui-policy-2026-11.md) §6。完成形の画像は `ui-targets/unit-overview.png`（未着手）、`ui-targets/unit-overview-ready.png`（段階完了）。

## 実装内容（仕様）

- 構成：パンくず → 標題 24/900 → ミッションバンド → 進捗行＋バー → 波マップ → 「発展ミッション一覧へ」テキストリンク → この単元の実績 → この単元の知識カード。パンくずは設計ドラフトにも出す。
- ミッションバンド（強調面 S2：白＋主色2px枠）：コース一覧と同一の場面サムネイル、チップ行（課題軸チップ＋目標フラグ）、ミッションの題、説明、達成の条件、主ボタン。状態で出し分ける：
  - 未着手：説明全文＋「学習を始める」
  - 学習中：説明は隠す。題と条件は残し、ボタンの上に「次は『段階名』」、ボタンは「学習を進める」
  - 段階完了（フェーズ1〜6完了）：全文＋「ミッションに挑戦する」
  - 達成済み：全文＋「単元の結果を見る」
  - 主ボタンの下に「どんな問題を解く？」（ストーリー提示への入口）を全状態で置く。挑戦できない理由の注記や、無効化した挑戦ボタンは置かない。
- 進捗行：「学習段階 n/6 完了」＋ミッション状態のチップ。進捗バーは緑 #16a34a（完了した量＝緑、で全画面統一）。
- 波マップ：7ノード（フェーズ1〜6＋最終ノード）。最終ノードのラベルは「最終チャレンジ」、下にミッションの題を添える。現在のノードは青く塗り118px 級＋浮遊チップ＋▶バッジ常時表示。完了ノードは白地＋緑の枠だけ＋白丸に緑の ↻ バッジ。ノードのクリックは直接遷移（確認を挟まない）。
- 任意フェーズ：1.5「予測・実験」はフェーズ1〜2の間の波の上に、6.5「実装の橋渡し」はフェーズ6と最終ノードの間の波の下に、80px の破線の小円＋破線の接続で置く。1.5 は常時利用可、6.5 はミッション挑戦可能になるまで灰色のロック表示。脚注：「任意フェーズは、学習段階の進捗には数えません。」
- 発展ミッションの接続はマップに置かない（小ノードは置かない）。マップ下の「発展ミッション一覧へ」テキストリンクだけが担う。
- この単元の実績／この単元の知識カード：実績はトロフィーの色＋チップで示し、未獲得でも淡くしない。知識カードは所持＝題＋説明、未所持＝「？？？」＋獲得場所（どのフェーズで得られるか）。
- 「概念の確認状況」セクションは置かない（表示だけの変更。到達の定義＝最終的に正解、フェーズ3・5・6のみ、初回正解率は別の小指標、という定義とフィードバック集計は変えない）。
- 読ませる文字は黒に統一する（灰色文字は使わない。灰色は文字でない状態符号だけ）。文字は14px 未満にしない。
- 用語：「目標」は学習者側だけの語。単元の課題は「単元ミッション」、修了後の課題は「発展ミッション」。

## 確認方法

1. 未着手／学習中／段階完了／達成済みの4状態で、バンドの出し分けとマップのノード状態を確認する。
2. 任意フェーズが進捗の分母（n/6）に入らないことを確認する。
3. スクリーンショットは約1093×614と約2560×1440の2サイズを PR に付ける。
