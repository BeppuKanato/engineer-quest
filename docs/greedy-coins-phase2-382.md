# 貪欲法（硬貨問題）フェーズ2（動きの説明）（Issue #382）

目的: 貪欲法（硬貨問題）単元のフェーズ2（動きの説明）を、基準データ §3 フェーズ2の11ステップ（主教材786円、1ステップ＝硬貨1枚の選択）に沿って実装する。設計は基準データ（docs/concept/greedy-coins-unit-baseline.md §1・§3、正本）に従う。最終確認日: 2026-11-11。前提: 硬貨図基盤とフェーズ1は #381（本 PR の base ブランチ）。

## 実装

- `front/src/features/learning/greedy-coins/execution/execution.types.ts`: フェーズ2の Canvas 型。硬貨の盤面（#381 の figure 盤面型）に、このステップで選んだ硬貨 `selectedCoin` を足す。検証は figure の盤面検証を再利用したうえで、選んだ硬貨がトレイの最後の1枚と一致すること、その額面が current であること、導入・まとめ（selectedCoin = null）では current が無いことを見る。
- `execution.content.ts`: 11ステップ。盤面は `../greedyCoins.ts` の実行記録（契約 greedy-coins-v1 の選択列）から組み立て、手書きしない。主教材の形（選択列 [500, 100, 100, 50, 10, 10, 10, 5, 1]、残額推移 786→286→186→86→36→26→16→6→1→0）を前提として検証する。
  1. `introduce` 全額面 upcoming、残り786円、トレイ空。「786円を、硬貨の枚数が少なくなるように、そのつど使える一番大きい硬貨を選んで払います。」
  2. `select-1` 500円を選択（残り286円、500が current）。
  3. `select-2` 100円を選択（残り186円、500が passed、100が current）。
  4. `select-3` 100円を選択（残り86円）。フェーズ3の場面はこのステップが担う。
  5. `select-4` 50円を選択（残り36円）。
  6. `select-5` 10円を選択（残り26円）。
  7. `select-6` 10円を選択（残り16円）。
  8. `select-7` 10円を選択（残り6円）。
  9. `select-8` 5円を選択（残り1円）。
  10. `select-9` 1円を選択（残り0円）。
  11. `summary` 全額面 passed、トレイ9枚の完成表示。「そのつど一番大きい硬貨を選ぶこの方法は貪欲法と呼ばれ、9枚で払えました。」
- `GreedyCoinsExecutionCanvas.tsx`: 盤面を figure の Canvas 形へ戻し、描画は `GreedyCoinsDrawing` へ委譲する。
- `GreedyCoinsExecutionPreview.tsx`: 共通 LearningPlayer への入口。単元フロー（接続 Issue）向けに任意の接続ポート（embedded / onLearningEvent / active / onComplete / nextLabel）を持ち、未指定なら単品ページとして動く。
- 単品プレビュー: 共有の `front/src/app/learning-preview/[contentId]/page.tsx` に `greedy-coins-execution` として登録した（他単元と同じ [contentId] 方式）。

## 留保（判断が必要な点）

- **キャプションの圧縮（要確認・基準設計内の矛盾）**: 基準データ §3 フェーズ2は見出しで「キャプションは全て1文」と定める一方、ステップ表のキャプションは全ステップ2文になっている（例: ステップ2「500円を選びます。残りは286円です」）。二分探索フェーズ2（PR #287）の先例に倣い、意味と数値を変えず1文へ圧縮した（例: 「500円を選んで、残りは286円です。」、ステップ1は2つの節を接続、ステップ11は「そのつど一番大きい硬貨を選ぶこの方法は貪欲法と呼ばれ、9枚で払えました。」）。図の状態・選択列・残額は表どおりを厳密に再現している。表の文言そのまま（2文）へ戻す判断もあり得るため、PR で確認したい。
- **current の意味**: 選択ステップの current は「そのステップで選んだ額面」とした。選んだ直後にはその額面は残額より大きくなる場合もある（例: select-1 の後に残り286円で500はもう使えない）が、図の変化点（いま選んだ硬貨）を指す表示として、フェーズ2の実況と一致する。次のステップでは passed へ移る。
- **まとめの盤面**: まとめは全額面 passed（グレー）とし、トレイ9枚の完成表示で到達を示す。完了表現に緑は使わず、キャプションで「9枚で払えました」と言語化する形にした。
