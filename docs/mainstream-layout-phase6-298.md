# 主流レイアウト移行（フェーズ6の3段組化）

- 目的: Issue #298 の移行シリーズ第2弾として、フェーズ6（応用問題）を「上部固定＋中央スクロール＋下部固定ゾーン」の3段組にし、図の高さをテキスト量から切り離す。
- 最終確認日: 2026-11-09
- 正本: Issue #298 と 2026-11-09 のユーザー承認（主流レイアウト移行の設計、C1 の方針変更を含む）。ベースは第1弾（結果画面の単一スクロール化）のブランチ。

## 変更内容

- 全5単元の応用問題プレビュー（`*ConsolidationPreview.tsx`）:
  - セクションを3段組に再構成。中央のスクロール領域（`flex: 1, minHeight: 0, overflowY: "auto"`）に問題文→図→指示・定義→選択肢（または Parsons 盤面）を上から流し、中央寄せ（`marginTop: "auto"` の安全な中央寄せ、#337）は廃止した。余白は中央領域の末尾に寄る。
  - 図の箱は `height: "min(54dvh, 600px)"` の固定高（旧 `flex: "1 1 auto"` ＋ `maxHeight` の上限方式、#339 を置き換え）。テキスト量・通知・誤答後の要素追加で図の大きさは変わらない。
  - 再回答の注記・復習ボタン・「次の問題へ／結果を見る」は下部の固定ゾーン（上罫で区切り）へ移動し、常時表示を保証する。
  - 診断（応用問題の結果）も同じ骨格で、スコア・論点別結果・完了文は中央領域、「次へ進む」は下部固定ゾーンに置く。
- 共有 `ParsonsBoard`（`bfs/consolidation/`）: scrollable の表示窓を固定高 368px（行ピッチ46px×8行）に変更。下限 276px（6行、#327）は床として維持。盤面の内側スクロールは学習画面で唯一の入れ子スクロールとして残す（承認済み設計 2-2）。
- 全5単元の単元コンテナ: 「直前の回答」通知を内側カラムの中から、ヘッダー直下の固定ゾーン（ラッパーの外）へ移動。通知の有無でフェーズ画面の開始位置と図の大きさが変わらない。
