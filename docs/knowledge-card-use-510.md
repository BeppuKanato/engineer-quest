# 知識カードの使い道（Issue #510）

目的: Issue #510 として、知識カードにアプリ内での使い道を持たせ、「集めるだけ」を解消する。適用範囲はカードとミッションの対応データ、発展ミッション挑戦画面での参照 UI、コレクションの表示。最終確認日: 2026-11-25。
正本・前提: 2026-11-19 の強化計画の決定（カードは再訪のエンジン、全ユーザーが全カード取得可能、カード表の廃止）、[redesign-overview-2026-11.md](redesign-overview-2026-11.md) §2.4。

## 実装内容（仕様）

- カードの行き先は発展ミッションとする。カード→ミッションの対応をデータとして持ち、旧「作るクエストへの対応」から付け替える。
- 挑戦画面での参照：挑戦中のミッションに関連するカードを参照として並べる。カードは文字のリストではなく「カードの面」で見せる：知識を表す絵、タイトル、詳細（説明・つながり・使いどころ）を最初から面に出し、ボタンで開く形にしない。「つながり」と「使いどころ」の表示で、そのミッションとの関係が一目で分かるようにする。未所持のカードは絵をシルエットにし、使いどころだけをプレビューとして見せる（中身は開けない）。配置はヒントと対応づけ、同じタブ（ヒント・カード）に置く。作業画面では横型のタイル（左に絵、右にタイトルと詳細）に圧縮してよいが、絵と詳細を面に出す点は変えない。カードは挑戦の必須条件にしない（1枚もなくても挑戦・クリアできる）。
- 復習のヒントとしてカードは使わない（カード参照は挑戦の場面に限る）。
- カードの useCase（使いどころ）の文は、アプリ内の次の行動に向けた持続的な状況として書く（例：「発展ミッションで、詰まったときに考え方を確認する」）。その場限りの消費（使ったらなくなる等）にはしない。
- 単元完了時の出口（単元フィードバックの後の行動選択）に、関連キーワードからカードを検索するリンクを置く。
- コレクション画面：各カードに「どこで使えるか」（対応する発展ミッション）を表示する。未所持のカードは獲得場所に加えて使い道も示す。

## 確認方法

1. 発展ミッションの挑戦画面で、所持カードの詳細が面に出ており、未所持カードがプレビュー止まりであることを確認する。
2. カードを1枚も持たない状態で挑戦が完了できることを確認する。
3. コレクションで各カードの使い道が分かることを確認する。
4. スクリーンショットは約1093×614と約2560×1440の2サイズを PR に付ける。対応データの seed 適用手順は PR に明記する。
