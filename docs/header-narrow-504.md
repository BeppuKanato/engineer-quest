# アプリヘッダーの狭幅対応（Issue #504）

目的: Issue #504 として、幅1093px級の画面でアプリヘッダー（ロゴ＋ナビ）が切れる問題を直す。適用範囲はフロントエンドの共通ヘッダー。最終確認日: 2026-11-24。
正本・前提: [redesign-ui-policy-2026-11.md](redesign-ui-policy-2026-11.md) §8。完成形の画像は `ui-targets/header-1093.png`。設計サンドボックスで検証済みの数値を移植する。

## 実装内容（仕様）

md 帯だけを詰め、lg 以上は現行どおりにする：

- コンテナの左右余白：md で 4 → 2（lg で 4 に戻す）
- ツールバーの間隔：md で 3 → 2（lg で 3）
- ナビの間隔：md で 1.5 → 1（lg で 2）
- ナビ項目の左右余白：md で 1.4 → 0.75（lg で 1.4）
- 「Engineer Quest」の副題は lg 未満で非表示

この組み合わせで 1093px と 980px では収まることを確認済み。約940px 未満ではなお切れるため、その帯域の扱い（折りたたみ等）は本 Issue の範囲外とする。

## 確認方法

1. 1093px 幅でナビ全項目とプロフィールアイコンが収まることを確認する。
2. 2560px 幅で現行と見え方が変わらないことを確認する。
3. スクリーンショットは約1093×614と約2560×1440の2サイズを PR に付ける。
