# Parsons盤面のはみ出し修正と「直前の回答」の表示ポリシー（Issue #318／#302／#303）

目的: 応用問題の Parsons 盤面が行数の多い単元で画面からはみ出す問題を直し、あわせて「直前の回答」が次の問題や結果画面に残る表示を、決まったポリシー（対象の問題を開いている間だけ表示）に統一する。
最終確認日: 2026-11-08

## Part 1: Parsons 盤面のはみ出し（Issue #318）

### 症状と原因

- 共有コンポーネント `ParsonsBoard`（`front/src/features/learning/bfs/consolidation/ParsonsBoard.tsx`）には縦の上限もスクロールもなく、盤面が行数に比例して伸びていた。行ピッチは約52px（行48px＋間隔4px）で、棒倒し法（21行）では盤面だけで約1,090pxになり、問題文・指示・「この順序で回答する」ボタンが画面外へ追い出され、ページ全体がスクロールしていた。穴掘り法（22行）でも同じ状態だった。

### 変更

- `ParsonsBoard` に `scrollable` を追加した。指定時は盤面領域だけが残り高さの中で縦スクロールし、ボタン行（提示順に戻す／この順序で回答する）は下に固定される。
- 行ピッチを52pxから46pxへ詰めた（行44px＋間隔2px）。内訳: 枠線を `border` から inset の `boxShadow` に変えて行高をボタン下限の44pxちょうどにし、行間を4px→2px、コードの `lineHeight` を1.8→1.5にした。↑↓ボタンのタッチ標的44pxが下限のため、ピッチ44pxちょうどにはできない（間隔0が必要になる）。コードのフォントサイズは変更していない。
- 全5単元（BFS／バブルソート／二分探索／穴掘り法／棒倒し法）の応用問題プレビューで、Parsons のときもセクションの高さを確定させ、`scrollable` を渡すようにした。Parsons 以外の問題の表示は従来どおり。
- フェーズ7ヒント（レベル4）の練習盤面も同じ `ParsonsBoard` を使うため、ピッチの共通化だけが効く。ヒントはダイアログ内表示でダイアログ側にスクロールがあるため、コンテナの扱いは変更していない。

### ドラッグ操作の留保

- スクロールする盤面の中でも、行のドラッグ（ハンドル起点）自体は動作する。ただし framer-motion の Reorder にはスクロールコンテナ端での自動スクロールがないため、見えていない位置まで一気にドラッグで運ぶことはできない。途中までドラッグして盤面をスクロールする操作か、↑↓ボタン（1行ずつ確実に移動）が代替になる。この留保は実機での最終確認を要する。

## Part 2: 「直前の回答」の表示ポリシー（Issue #302／#303／#318）

### 症状と原因

- `AnswerFeedbackNotice` の文言は assessment 単位で保持され続け、単元プレビューが画面種別を問わず描画していたため、最後の問題のフィードバックが結果画面にも残り、棒倒し法フェーズ6では見出し「応用問題の結果」に重なって描画されていた。次の問題へ進んでも前の問題の回答が残る点も #302/#303 で指摘されていた。

### 変更（ポリシー: 対象の問題を開いている間だけ表示）

- 共通フック `useAssessmentFeedback`（`front/src/features/learning/assessment/AnswerFeedback.tsx`）で、新しいフィードバックが無いときに残存通知を点検し、今開いている問題と異なれば消すようにした。次の問題へ進んだ場合と、全問終了で結果になった場合の両方に効く。回答直後にその問題の画面で表示する経路（present）は変更していない。
- 単元プレビュー（全5単元）では、通知を問題画面（screen.kind === "phase"）でのみ描画し、結果画面・ブリッジ・単元最終結果では描画しないよう配置側でも限定した。

## 検証

- verify: 全5単元の consolidation／unit、BFS・バブルソート・棒倒し法の check／code-check、BFS・棒倒し法の implementation、verify:learning-player が通過。
- front の typecheck と build が通過。変更ファイルの lint はエラーなし（既存の警告のみ）。
- 実機確認は未実施（要確認）: 実効約1093×614 CSS px で棒倒し法フェーズ6の Parsons がページスクロールなしに収まること、盤面内ドラッグの感触、バブルソート フェーズ5／6 と棒倒し法フェーズ6で「次の問題へ」後に通知が消え、結果画面に通知と重なりが無いこと。
- DB 適用は不要（フロントエンドのみの変更）。
