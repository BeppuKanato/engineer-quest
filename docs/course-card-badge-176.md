# コースカードの二重バッジ解消（Issue #176）

目的: コース一覧・ホームの単元カードで、完了した単元に「クリア済み」と「コースクリア」の2つのバッジが並ぶ問題を直す。最終確認日: 2026-11-06。

## 調査結果

- 2つのバッジはどちらも `CourseCard`（`front/src/app/courses/component/courseCard.tsx`）内で、**全く同じ条件**（`status === "completed"`）から出ていた。
  - `StatusChip`（アプリ共通の状態チップ）: 未着手／進行中／**クリア済み**
  - 追加チップ: **コースクリア**
- 意味も色（緑系）も同じで、情報の追加はなかった。

## 判断と実装

- 残すのは `StatusChip` の「クリア済み」。理由: アプリ共通の状態語彙であり、コース一覧の絞り込み（`courseFilter`）の表記とも一致する。「コースクリア」は CourseCard だけの局所表現で、用語の方向（単元）とも合わない。
- 「コースクリア」チップと、不要になったアイコン import を削除した。完了時の進捗バー色・「復習する」ボタンなど、他の完了表現は変更していない。

## 検証

- `verify:home-layout` に、CourseCard に「コースクリア」が残っていないこと・StatusChip が維持されることを固定した。
- 全 verify・front の lint・typecheck・build が通過する。

## 確認方法

スクリーンショットは環境の都合で未取得のため、見え方はデプロイ後の実機確認に委ねる。

1. 完了した単元（BFS）のカードで、バッジが「クリア済み」1つだけになることを確認する。
2. 進行中・未着手のカードの表示が変わっていないことを確認する。
