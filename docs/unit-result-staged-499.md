# 単元リザルトの2ステージ化（Issue #499）

目的: Issue #499 として、単元完了時の最終リザルトを「祝う」と「成果と報酬」の2ステージに分けた確定形に刷新する。適用範囲はフロントエンドの最終リザルト表示。最終確認日: 2026-11-24。
正本・前提: [redesign-overview-2026-11.md](redesign-overview-2026-11.md)、[redesign-ui-policy-2026-11.md](redesign-ui-policy-2026-11.md) §5.4、完成形の画像は `ui-targets/unit-result-stage1.png` / `ui-targets/unit-result-stage2.png`。設計サンドボックス `engineer-quest-ui-brushup` で実装・確定済みの形を移植する。本書は `unit-final-result-150.md` の提示決定（実績のコンパクト要約、達成の青で灯すミニマップ等）を置き換える。

## 実装内容（仕様）

### ステージの切り替え

- 到達直後（fresh）はステージ制にする。ステージ1（祝う）→ 前進ボタン → ステージ2（成果と報酬）。ステージ2へ移ったら画面先頭へスクロールし、見出しへフォーカスする。
- 再訪時（結果の見直し）はステージ制にせず、両ステージの内容を1ページに全表示する。
- ステージ1の前進ボタンは、学習経路ミニマップの描画が終わってから（約2.3秒）出す。

### ステージ1（祝う）

- 紙吹雪は final プリセット。祝福の面は金の放射グラデーション（枠線は付けない）＋きらめきの装飾。
- トロフィーのメダリオンは 144px の真円（潰れないよう縮小させない）。金 #d97706 はこことゴールノードと祝福の面に限る。
- 修了見出しは「{単元名}修了！」44px/900。称賛の主見出し 26px は結果に応じて出し分ける（優先順：ヒント0回かつテスト実行1回 → 「しかも、ヒントなしで一発クリア！」／ヒント0回 → 「しかも、ヒントなしでクリア！」／全問初回正解 → 「しかも、全問初回で正解！」／つまずきがあって全部解き切った → 「つまずいても、全部解き切った！」／それ以外 → 「ついに、自分の力で実装できたね！」）。タイトル＝修了の事実、主見出し＝その学習者の具体的な成果、吹き出し＝学習の弧、と役割を分け、同じ内容を二度言わない。
- マスコット（celebrate、300px 級）にセリフ吹き出しを重ねて一体のシーンにする。吹き出しの文は「{導入の理解}から始めて、最後は自分でコードを書けるようになったね。」の形で、核の句「自分でコードを書ける」だけ濃い金・太字にする。
- ミッション達成バンドは金の面の中に置く（金2px枠、#fffbeb）。学習前のサムネイルと学習後のサムネイルは同サイズ（300px 級）で並べ、金の矢印を挟む。学習後は本がバラバラの位置から番号順の位置へバネで移動するアニメーション（約0.9秒遅延で開始、並び切った後にきらめき）。動きを減らす設定では並び切った静止画にする。「✓ 単元ミッション達成」チップ＋見出し「{ミッションの題を達成形に}！」24px/900。
- 「この単元で学んだステップ」ラベルチップ（本アイコン、青ピル）の下に学習経路ミニマップ（幅1060まで、単元画面と同じ波形・同じ幾何を使うこと。ノードには大きな白い ✓、ゴールノードは金＋白い星、フェーズ名ラベルをノード下に置く。軌跡1.4秒で描画、ノードは線が届く順に灯り、描き切りに全体の弾み）。
- 前進ボタンは幅広ピル（最大720、高さ56以上）で「学習成果を見る（新しい実績 N 件）」。

### ステージ2（成果と報酬）

- 見出し「今回の学習成果」24/900、金のきらめきで挟む。
- 成果タイル（全幅1060、3枚）：アイコン＋見出し行（17〜20/900）→ 数値 38/900（青）→ 補足はピル。タイル1の見出しは全問初回正解なら「全問正解」、そうでなければ「全問題クリア」、ピルは「初回正解 n問」。タイル2のピルは「最終チャレンジのテスト実行」（範囲を明示する）。タイル3の数値は常に「n 回」とし、ピルで「ヒント未使用」／「ヒントを手がかりに」を出す。
- 新しい実績ゾーン：見出し（金のトロフィーアイコン＋「新しい実績を獲得！」＋件数の金チップ）。カードは4列（広い画面）、メダル主役（カード配置では行配置より +16px）、レアリティは白ピル（レアリティ色の枠）、隅にきらめき。メダルの造形はレアリティで変える（コモン＝素の円／レア＝リボンの尾／エピック＝尾＋二重リング／レジェンダリー＝尾＋リング＋星飾り）。アイコンはマスタの iconKey 割当（build/challenge/course/perfect/knowledge）を使う。入場の弾みはレアリティで差を付ける（コモン 0.96／レア 0.88／エピック・レジェンダリー 0.8 から）。解除音はバッチで1回だけ鳴らす。
- 次の実績の行（幅1060）：トロフィー円 52px、題 18/900、レアリティはレアリティ色の文字、説明 14、区切りゲージ（目標21以下はセグメント、満たした分は緑 #16a34a、次の1つは緑の輪郭、残りは #e7edf5。21超は割合バー）、「{進捗} / {目標}」16/900＋緑チップ「あと {残り}」。選出規則は、表示中の未解除実績のうち進捗率が最大のもの（今回解除したものは除く。同率は先勝ち）。この規則は暫定であり、変更する場合は PR で明示する。
- 到達状況は枠つきアコーディオン：バー（青い ✓＋「全7ステップ完了」＋「復習候補：nステップ」＋シェブロン）を開くと、元のフェーズ行7件が同じ枠の中に出る。復習候補チップはフェーズ名の直後、復習ボタンは行の右端。閉じた状態で情報が欠けないこと（要約はバーに全部入れる）。
- 大目標の達成表示が残る場合はこの位置に出す（大目標システム自体は redesign-overview §2.3 により撤去予定。本 Issue では表示の置き場だけを確保し、撤去は別 Issue）。
- 締めの段落や注記など、文字だけのパートは置かない。
- 出口はフィードバックのバナーだけ：青グラデーション（#2563eb→#1d4ed8）の面に、マスコット（point、110px 級）＋「今回の成長を振り返ろう！」20/900（白）＋「できるようになったことや、次に挑戦するとよいことを確認しよう。」＋白ピルのボタン「自分へのフィードバックを見る」。コース一覧への戻りボタンは置かない（ヘッダーのナビは共通部品として残る）。フィードバックが存在しない単元ではバナー自体を出さない。

## 確認方法

1. バブルソート単元を最後まで完了させ、ステージ1（金の面、トロフィー、並び替わる本、ミニマップ、前進ボタン）を確認する。
2. 前進ボタンでステージ2へ移り、成果タイル、実績カード、次の実績、到達状況アコーディオン、フィードバックバナーを確認する。
3. 結果を再訪し、1ページ全表示になることを確認する。
4. 動きを減らす設定で、アニメーションなしの完成状態になることを確認する。
5. スクリーンショットは約1093×614と約2560×1440の2サイズを PR に付ける。
