# 貪欲法（硬貨問題）硬貨図基盤とフェーズ1（導入）（Issue #381）

目的: 貪欲法（硬貨問題）単元の硬貨図基盤（額面列＋残額＋選んだ硬貨のトレイ）とフェーズ1（導入）を、基準データ §3 フェーズ1・§4 に沿って実装する。設計は基準データ（docs/concept/greedy-coins-unit-baseline.md、正本）に従う。最終確認日: 2026-11-11。

## 実装

- `front/src/features/learning/greedy-coins/greedyCoins.ts`: 単元の実行データを組み立てる正本。参照コード（契約 greedy-coins-v1）と同じ手順で硬貨1枚ごとの選択（硬貨・残額の前後）を記録する `greedyCoinsSelections`、戻り値（選択順のリスト）を返す `runGreedyCoins`、主教材・転移・反例の検証済み定数。額面は降順で渡される前提を検証し、関数内では並べ替えない。入力は変更しない。
- `figure/greedyCoins.types.ts`: 硬貨の盤面型（本 Issue の中核）。盤面は額面列 `coins`、額面ごとの状態 `coinStatuses`（current＝今見ている／upcoming＝まだ先／passed＝通過済み）、金額 `amount`、残額 `remaining`、選んだ硬貨のトレイ `tray` で構成する。検証は意味の整合まで見る: 額面は厳密な降順、状態は passed → current → upcoming の順を崩さない（current は最大1つ）、トレイは額面のいずれかで選択順（単調非増加）、トレイ合計＋残額＝金額、強調は額面チップだけ。
- `figure/greedyCoinsGeometry.ts`: 600×450 の論理座標に額面列（中心 y=104、半径38）・残額（y=224、40px）・トレイ（y=296〜396、小チップ半径24）を縦一直線に配置する寸法の正本。全場面で同じ位置・大きさにし、図の大きさが場面で変わらないようにする。
- `figure/GreedyCoinsDrawing.tsx`: 硬貨の図の唯一の描画実装。額面状態からプレイヤートークンへの写像は current＝処理中（青 #2563eb）、upcoming＝未到達（ベージュ #f5e7c1）、passed＝通過済み（グレー #e5e7eb）で、すべて `playerTokens` から取る（HEX の直書きなし、緑は使わない）。情報テキストは黒、青いチップの上だけ白。トレイの硬貨は額面チップの小型版（ベージュ）で示し、枚数を併記する。
- `motivation/motivation.types.ts`: フェーズ1の Canvas 型。盤面型に出口（`{ label, nextPhase }`、他単元フェーズ1と同じ形）だけを足し、盤面の検証は figure 側を再利用する。
- `motivation/motivation.content.ts`: 7場面（すべて完全スナップショット、キャプションは1文）:
  1. `small-coins-burden` 786円を小さい硬貨だけで払う負担の提示（1円チップを強調）。「786円の買い物を小さい硬貨だけで払おうとすると、硬貨が何百枚も必要になってしまいます。」
  2. `six-coins` 日本の硬貨6種類の提示。「日本の硬貨は、500円、100円、50円、10円、5円、1円の6種類あります。」
  3. `large-coin-first` 500円を1枚選んだ盤面（残り286円）。「500円のところは500円硬貨1枚で済みますが、1円硬貨では500枚も必要です。」
  4. `large-to-small-demo` 大きい順に払う圧縮版の実演（トレイ9枚、残り0円、全額面 passed）。「大きい硬貨から順に使うと、786円を9枚の硬貨で払えます。」
  5. `next-largest` 残り86円で次に使える一番大きい硬貨（50円）を current で示す。「残りが86円になったら、次に使える一番大きい硬貨は50円です。」
  6. `unit-overview` 単元の見通し。「この単元では、この払い方を、動きの確認からコード、そして自分で実装するところまで順に学びます。」
  7. `main-example-preview` 主教材の予告（500円チップを強調）＋ exit（`{ label: "動きの説明へ進む", nextPhase: 2 }`）。「次からは、786円を9枚で払う過程を、硬貨1枚ずつ見ていきます。」
- `motivation/GreedyCoinsMotivationCanvas.tsx`: 描画は `GreedyCoinsDrawing` へ委譲し、出口ボタンの重ね方だけを持つ。
- `motivation/GreedyCoinsMotivationPreview.tsx`: 共通 LearningPlayer への入口。単元フロー（接続 Issue）向けに任意の接続ポート（embedded / onLearningEvent / active / onComplete）を持ち、未指定なら単品ページとして動く。
- 単品プレビュー: 共有の `front/src/app/learning-preview/[contentId]/page.tsx` に `greedy-coins-motivation` として登録した（他単元と同じ [contentId] 方式）。
- 用語「貪欲法」はフェーズ1では出さない（基準データ §3。名称付けはフェーズ2の最後に置く）。用語表は日常語（残り／使える一番大きい硬貨）と後続フェーズの語（残額）の対応だけを持つ。
- 結果画面の図 `GreedyCoinsResultFigure`（基準データ §4）は本 Issue の範囲外とし、単元コンテナ・接続（#389）で扱う。

## 留保（判断が必要な点）

- **配置の判断**: Issue #381 本文は新規描画基盤を `front/src/features/learning/player/` 相当の共有配置に置くとしていたが、基準設計 §4 は「新しい図コンポーネントを単元側に持つ」と明記するため、基準設計を優先して `front/src/features/learning/greedy-coins/figure/` に置いた。PR 本文にも同旨を記録する。
- **場面1の見せ方**: 「小さい硬貨だけで払う」場面を、硬貨を何百枚も並べる図にはせず、全場面共通の盤面のまま1円チップを強調し、負担はキャプションと残額（786円）の大きさで示した。図の大きさと配置を全場面で一致させる（配置安定性）を優先した判断であり、実機で負担の伝わり方が弱ければ場面1専用の図の追加が要る。
- **場面2の図**: 硬貨6種類の提示は場面1と同じ初期盤面で、差は強調の有無とキャプションだけである。額面列そのものが提示対象であるため図の差し替えは不要と判断した。
- **トレイの硬貨の色**: トレイ内の硬貨は額面チップの小型版として、未到達と同じベージュのトーンで示した（基準データ §4「トレイ内の硬貨は額面チップの小型版で示す」）。状態色ではなく種類の色として使っている点は、実機レビューで確認したい。
