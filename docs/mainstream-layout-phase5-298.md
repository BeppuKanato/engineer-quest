# 主流レイアウト移行（フェーズ5の3段組化）

- 目的: Issue #298 の移行シリーズ第4弾として、フェーズ5（コードの確認問題）を「中央スクロール＋下部固定ゾーン」の3段組にし、コード窓の高さを固定する。
- 最終確認日: 2026-11-09
- 正本: Issue #298 と 2026-11-09 のユーザー承認。ベースは第3弾（フェーズ3の3段組化）のブランチ。

## 変更内容

- 全5単元のコード確認プレビュー（`*CodeCheckPreview.tsx`）:
  - 問題文とコード窓を中央のスクロール領域へ移した（C5: 問題文は中央領域に置く）。
  - コード窓は `flex: 1` の残り高さ方式から **高さ 320px の固定**へ変更（承認済み設計）。窓の内側スクロール（縦横）と、空欄を視界へ寄せる処理（#317）はそのまま維持する。問題が無い完了状態のスペーサーも同じ 320px にし、状態で高さが変わらないようにした。
  - 指示・選択肢・再回答の注記・復習ボタン・「次の問題へ／結果を見る」は下部の固定ゾーン（上罫で区切り）にまとめ、常時表示を保証する。選択肢はもともと下部の `flexShrink: 0` 領域にあったため、実質の移動はゾーンとしての明示化である。
- #321 のフロー契約（完了時は結果画面へ直行、フィードバックは保存成功後にマウント）は単元コンテナ側の話であり、本弾では変更していない。関連する検証（unit×5、learning-screens）は全て通過している。

## 検証

- `verify:<unit>-code-check`（5単元）にコード窓の固定高・中央スクロール・下部固定ゾーンの契約を追加し全て通過。`verify:learning-screens`、`verify:<unit>-unit`（5単元）も通過。
