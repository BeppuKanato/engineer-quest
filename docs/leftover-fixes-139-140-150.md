# Issues #139・#140・#150 残りの個別修正（パンくず／フロー矢印／リザルトのスクロールと終了導線）— 実施記録

実機レビュー（#137〜#150）のうち、判断を要しない個別修正（分類 C）をまとめて対応した。各 Issue には他の論点（レイアウト設計、用語、賞賛演出など）が残るため、本対応では Issue は閉じない。

## 1. パンくず未使用（#139, #140）

- 単元画面と学習画面は、戻り導線が画面ごとに違う素のボタンだった（「コース一覧へ」「単元画面へ戻る」）。
- 対応: アプリ全体で使われている共通部品 `AppBreadcrumbs` に寄せた。
  - 単元画面（`UnitOverview`）: コース ＞ 単元名
  - 学習画面（`LearningScreen`）: コース ＞ 単元名 ＞ 学習（compact 表示）
- 既存のボタンが担っていた遷移先はパンくずのリンクでそのまま辿れる。

## 2. フロー表示を矢印でつなぐ（#140）

- 学習画面上部のフェーズチップは並んでいるだけで、流れとして読めなかった。
- 対応: `BfsUnitPreview` のナビゲーションで、チップとチップの間（単元リザルトチップの前を含む）に `aria-hidden` の矢印アイコンを挟んだ。チップ自体の遷移・状態表現・文言は変更していない（文言は用語提案の判断待ち）。

## 3. 単元リザルトのスクロール（#150）

- 原因: 最終リザルト（`UnitFinalResult`）が専用の `overflowY: "auto"` を持ち、コンテンツ列（84vw）の右端にスクロールバーが出て、画面端から浮いて見えた。
- 対応: 最終リザルト表示時のみ、スクロールを外側の全幅コンテナ側に移した。リザルト自身は内側スクロールを持たない。フェーズ画面のレイアウト（固定表示）には影響しない。

## 4. 単元リザルトの終了導線（#150）

- 終了ボタンは「単元の先頭に戻る」（フェーズ1へ移動）だった。
- 対応: 「コース一覧に戻る」（`/courses` へのリンク）に変更した。復習は従来どおり、各フェーズの「復習する」と上部ナビから可能。

## 検証

- `verify:bfs-unit` に契約を追加した: ナビの矢印、両画面の `AppBreadcrumbs` 使用、最終リザルトが内側スクロールを持たないこと、終了導線が `/courses` であることとその文言。
- front の lint / typecheck / build と verify 全16件が成功。判定・保存・賞賛提示のロジックは変更していない。DB・シードの変更なし。
- GPT の PR #158（#144、同じ `UnitResultScreens.tsx` のフェーズ3・5リザルト側）とは変更箇所が別の関数で重ならない。

## 確認方法（マージ後・ローカル実行時）

1. 単元画面: 上部にパンくず（ホーム ＞ コース ＞ 幅優先探索（BFS））が出て、「コース」からコース一覧へ戻れること。
2. 学習画面: ヘッダー下にパンくず（ホーム ＞ コース ＞ 幅優先探索（BFS）＞ 学習）が出て、単元名から単元画面へ戻れること。上部のフェーズチップの間に矢印が表示され、流れとして読めること。
3. 単元リザルト: 内容が長いときにスクロールバーが画面の右端に出ること（コンテンツ列の内側に出ない）。最下部のボタンが「コース一覧に戻る」で、押すとコース一覧へ遷移すること。
