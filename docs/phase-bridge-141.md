# フェーズ間ブリッジの追加（Issue #141）

目的: Issue #141 として、フェーズが変わるタイミングに、次のフェーズの目標を短く伝えるステップ（ブリッジ）を挟む。適用範囲はフロントエンドの単元フロー遷移と教材指針の遷移モデル。最終確認日: 2026-11-06。
決定の経緯: 原案（Google Doc「2026-11-06_フェーズ間ブリッジ-原案」）をユーザが確認し、(1) 統一案（全遷移にブリッジ、リザルトの予告はブリッジへ移す）、(2) つなぎ文の文面、を承認した。従来の遷移は形がばらばらで、次の目標を伝える場所は 3→4 と 5→6 のリザルト予告文だけだった（2→3 と 4→5 はシームレス直結、1→2 と 6→7 はボタンのみ）。

## 実装内容

- ブリッジ画面 `front/src/features/learning/bfs/unit/PhaseBridgeScreen.tsx` を追加した。構成は次のステージのアイコン（円盤）、「ステージ n / 7」、見出し「次は「{正式名称}」」、つなぎ文、行き先名を持つ進むボタン（既存の `PhaseNextButton`）。見出しへ初期フォーカスを移す点はリザルト画面と揃えた。
- つなぎ文はコンテンツ層 `unit.content.ts` の各フェーズ `bridge`（フェーズ2〜7の入場文）に持つ。文面は原案どおりの承認済みテキスト。仕組みは単元共通の形なので、DFS 以降は文面を書くだけでよい。
- 遷移種別を整理した：`bridge` / `result` / `result-in-phase` / `final`（旧 `choice` / `seamless` を廃止）。前進の完了フローでは、完了 →（リザルトがある遷移はリザルト →）ブリッジ → 次のフェーズ、の順に進む。フェーズ6は内の結果のボタンからブリッジへ進む。
- リザルト画面（フェーズ3・5）は事実のみにし、次フェーズ予告文（`result.nextPreview`）を廃止した。進むボタンは「次へ進む」とし、行き先の正式名称を持つボタンはブリッジ側に置く。
- ブリッジを出すのは前進の完了フローだけ。復習・単元ナビゲーションからの移動・途中再開では出さない（`goToPhase` の復習判定は、ブリッジから自フェーズへ進む場合を前進として扱うよう調整）。
- 学習ログに `phase_bridge_view`（行き先フェーズキー付き）を追加した。滞在の切り分けのためで、実験条件や提示内容には影響しない。
- ステージアイコンを `front/src/features/learning/app/learningPhaseIcons.ts` に切り出して共通化し、単元画面のマップとブリッジで共有する（旧 `UnitOverview` 内のローカル定義を移設）。
- 教材指針 `docs/concept/learning-materials-guideline.md` を改訂した：共通制約に「フェーズ間のブリッジ」を追加し、シームレス接続（タイプB）とタイプCの予告部分の廃止を明記。フェーズ1・3・4・5 の該当箇所に改訂注記を付け、本項が優先することを示した。Drive 側の指針ドキュメントへの反映は別途行う。

## 検証

- `verify:bfs-unit`（拡張）: 遷移種別の並び、ブリッジ文の存在（フェーズ2〜7、フェーズ1は持たない）、リザルトが予告を持たないこと、ブリッジ画面の SSR（見出し・つなぎ文・行き先ボタン）、プレビューのブリッジ経由ルーティングと `phase_bridge_view` の記録を固定した。
- 上記を含む全 verify、front の lint・typecheck・build が通過する。

## 確認方法

対象 URL は http://localhost:3000/courses/roadmap/course-algorithm-breadth-first-search-v1/learn （ログインと進捗が必要）。スクリーンショットは環境の都合で未取得のため、見え方はデプロイ後の実機確認に委ねる。

1. 導入を完了させる。「次は「動きの説明」」と例文のつなぎ文が出て、ボタンで説明が始まることを確認する。
2. 動きの説明 → 動きの確認問題、動きとコードの対応 → コードの確認問題でも、直行せずブリッジが挟まることを確認する。
3. 動きの確認問題のリザルトに予告文がなく、ボタンが「次へ進む」になっていること、その先でブリッジ（動きとコードの対応）が出ることを確認する。コードの確認問題 → 応用問題も同様。
4. 応用問題の結果から「自分で実装へ進む」を押すと、実装の前にブリッジが出ることを確認する。
5. ナビゲーションのチップから過去のステージへ移動したときは、ブリッジが出ないことを確認する。
