# マージソートコース設計票

作成・調査日: 2026-09-25。コースID: `course-algorithm-merge-sort-v1`。

## 選定理由

既存コースにはバブルソート、選択ソート、二分探索、KMP法、BFS、DFSがある。BFS・DFSと探索が続いた後に題材を配列の並べ替えへ戻し、DFSで具体的に学んだ再帰を別分野で再利用できるアルゴリズムとしてマージソートを選ぶ。バブルソートと選択ソートの「同じ配列の中で比較と交換を繰り返す」方法に対し、「小さく分け、整列済みの結果を結合する」という分割統治の考え方を導入できる。計算量の証明よりも、分割と結合がなぜ正しい並びを作るかを具体的に追う。

## 想定する学習者

大学生、Python経験半年〜2年を中心とするが、マージソートと分割統治は未経験として扱う。変数、整数のリスト、添字、if、while、関数、returnを一度学んだ経験を想定する。再帰はDFSコースで見た可能性があるが、別の処理へ自力で応用できることは前提にしない。

英語変数名、スライス記法、床除算、再帰の停止条件、整列済みという不変条件、計算量表記を自力で解読できることは前提にしない。前Activityの具体的な配列や位置を覚えていること、外部検索を続けることも求めない。

## 前提知識

整数リスト、添字、`len`、if、while、関数、return、`append`を一度学んだ経験を想定する。スライス、`//`、`extend`、再帰の停止条件、再帰の返り値を変数へ記録する方法は本コース内で具体例から導入する。バブルソート、選択ソート、DFSの受講は必須にしない。

## 過去の学習方法と離脱要因

授業、動画、Web教材、サンプルコード、AIへの質問で、見本を実行・部分変更した経験を想定する。完成コードから再帰、スライス、2本の位置、残り要素の追加を同時に説明すると、どこから追えばよいか分からず離脱しやすい。分割図だけを見せて結合の選択過程を省く場合も、「なぜ最後に整列するのか」が暗記になる。

## 与える体験と学習価値

同じ問題を小さくして解き、解けた小問題を規則どおりに結合すると全体が解ける、という処理イメージを作る。最初は4要素を1要素まで分ける。次に、整列済みの2列の先頭だけを比較し、小さい方を結果へ移す。分割と結合を別々に理解した後で再帰コードへ対応づけ、最後に`merge_sort(numbers)`を自力実装する。

## 解決する問題と扱う範囲

整数リストを受け取り、値を失わず、小さい順の新しいリストを返す。入力リストは変更しない。空、1件、整列済み、逆順、重複、負数、奇数個を扱う。

ボトムアップ版、インプレース版、外部ソート、並列化、厳密な再帰式の解法、比較回数の証明、安定性の形式的な証明、オブジェクトのキー指定は扱わない。等しい値では左側を先に選ぶ実装にするが、「安定ソート」は発展事項として名称の紹介に留める。

## 開始時点と完了時点

開始時点では、バブルソートや選択ソートで配列を並べ替えられても、配列を分けることがなぜ並べ替えにつながるか、2つの整列済みリストを漏れなく結合する方法、再帰がどこで止まるかを説明・追跡できない。

完了時には、1要素以下はすでに整列済みだと判断し、配列を左右へ分け、左右を再帰的に整列し、各先頭の小さい方を結果へ追加し、残りを追加して全体を返せる。未見の整数リストでも処理順と中間状態を追い、関数を実装できる。

## 頭の中に作らせたい処理イメージ

複数要素のリストを中央で左右に分ける。左右にも同じ処理を行い、空または1要素になったら、そのリストはすでに整列済みとして返す。戻ってきた左右はどちらも整列済みなので、それぞれの未使用部分の先頭を比較し、小さい方を結果の末尾へ移す。片方が空になったら、もう片方の残りはすでに順番どおりなので、そのまま末尾へ追加する。

## 用語の導入順

小さく分ける→1要素なら並べ替え不要→小さい問題にも同じ処理を使う→再帰→整列済みの2列を1列へまとめる→結合（マージ）→分割してマージする→マージソート→分割統治。正式名称は具体的な動きを理解した後に置く。

コードは`len(numbers) <= 1`、`middle = len(numbers) // 2`、スライス、左右への再帰呼び出し、`merged`、2つの位置`i`と`j`、`while`、`append`、`extend`、`return`の順に導入する。`//`は小数点以下を使わない割り算、スライスの終了位置は含まないことを同じ画面で具体例から説明する。

## 想定する誤解とフィードバック

- 分割した時点で左右が整列する: 分割直後の値順は変わらず、再帰から返った左右だけが整列済みと区別する。
- 中央の値を特別扱いする: `middle`は境界位置であり、二分探索の比較対象ではない。終了位置を含まないスライスで説明する。
- 1要素でなく空まで分ける必要がある: 1要素以下はすでに整列済みとして止める。
- 未整列の左右をマージする: マージの前提として左右が整列済みであることを毎画面に再掲する。
- 全要素から最小を探す: 整列済みの各列では未使用の先頭が最小なので、2つだけ比べればよい。
- 等しい値を一つ消す: `<=`なら左を1つ追加し、右の同じ値は後で追加される。
- 片方が空になると終了する: もう片方の残りをすべて結果へ追加してから返す。
- 再帰呼び出しの戻り値を使わない: 左右は「整列済みリストとして返った値」を変数へ記録する。

## 正解コード

```python
def merge_sort(numbers):
    if len(numbers) <= 1:
        return numbers
    middle = len(numbers) // 2
    left = merge_sort(numbers[:middle])
    right = merge_sort(numbers[middle:])
    merged = []
    i = 0
    j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            merged.append(left[i])
            i += 1
        else:
            merged.append(right[j])
            j += 1
    merged.extend(left[i:])
    merged.extend(right[j:])
    return merged
```
