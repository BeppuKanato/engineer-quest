## 想定する学習者

大学などでプログラミングを学び始めて半年から2年程度の学習者を中心とする。文字列探索アルゴリズム、接頭辞・接尾辞、LPS、KMP法は未経験とし、英語変数名から役割を推測できることや前画面の値を記憶していることは前提にしない。

## 与える体験と学習価値

学習者は、まずpatternを1文字ずつずらす単純な文字列探索を実行し、同じtextの文字を比較し直す場面を発見する。実際の横ずらしを確認した後で、新しい配置でも一致すると分かる文字をpatternの先頭と一致部分の末尾から判断する。使える最大文字数をLPS表へ記録し、検索で使う効果を体験した後、表を効率的に作るPythonコードへ進む。

修了時には、次をできる状態を目指す。

- textとpatternの現在配置、比較中の2文字、次の配置を追える
- `LPS[k]`が、不一致後の新しい配置でも使える最大文字数だと説明できる
- `lps[pattern_index - 1]`と`lps[length - 1]`の役割を区別できる
- LPS表作成と検索を含む`kmp_search`を実装し、テストで修正できる

## 可視化方針

### text検索

各Activityの中心コンセプトに必要なものだけを表示する。indexや変数名は、その位置をコードやLPS表へ対応づけるActivityでのみ表示する。

- textとpatternの配置
- 現在比較する2文字
- 実際に一致を確認した範囲
- 配置変更を扱う場合は変更前後
- コード接続ではtext_indexとpattern_index
- LPS表を使う場合は参照位置

愚直な開始位置1の判定では、実際の検索どおりBとAの1文字比較を表示する。開始位置2でも、愚直法はA同士のif判定を実行する。LPS表を導入する前に「比較し直さない」とは説明しない。実際に確認済みの`text[2] = pattern[2]`と、事前に確認できる`pattern[2] = pattern[0]`を分けて示し、LPS表がこの関係を記録した後でのみ再比較を省く。

### LPS値の手計算

- 今回調べる範囲の長さをmとする
- 先頭と末尾から同じ数だけ取り出す文字数をxとする
- `1 <= x <= m - 1`を日本語と具体例で先に説明する
- `x = m`は文字列全体どうしになり必ず一致するため除外する
- 1ステップでは1つのxだけを比較する
- すべてのxを確認した後で最大の一致をLPS値へ記録する

### LPS表の効率的な作成

Mission 6では、規則の説明と具体例の追跡を別Activityに分ける。概念順は「手計算の候補数は約n² → 一致済み部分の直後だけを比べる規則 → ABABを最初から追跡 → 不一致時にLPS値を文字数として読む規則 → ABABAAを最初から追跡 → コード対応」とする。追跡画面は、既知の一致範囲を緑、今回比べる2文字を青、不一致を赤で統一し、1ステップでは比較・記録・候補変更のいずれか1つだけを行う。

各Activityには中心コンセプトに必要なpattern、現在の候補、今回比べる2文字、作成途中のLPS表だけを表示する。`i`と`length`は具体的な動作を理解した後に導入する。色だけで意味を伝えず、日本語ラベルと実際の文字列を併記する。再生の1ステップは、比較・LPS値の記録・候補変更のいずれか1つだけを表す。

Mission 6のActivity構成は次のとおり。

1. 手計算で調べる候補数を数えよう
2. 一致が分かっているときの次の一手を知ろう
3. ABABのLPS表を最初から作ろう
4. 不一致のときにLPS値をどう使うか知ろう
5. ABABAAのLPS表を一手ずつ完成させよう
6. LPS表作成コードを組み立てよう
7. 次の状態を判断しよう

## 正解コード

```python
def kmp_search(text, pattern):
    if pattern == "":
        return 0

    lps = [0] * len(pattern)
    length = 0
    i = 1
    while i < len(pattern):
        if pattern[i] == pattern[length]:
            length += 1
            lps[i] = length
            i += 1
        elif length > 0:
            length = lps[length - 1]
        else:
            lps[i] = 0
            i += 1

    text_index = 0
    pattern_index = 0
    while text_index < len(text):
        if text[text_index] == pattern[pattern_index]:
            text_index += 1
            pattern_index += 1
            if pattern_index == len(pattern):
                return text_index - pattern_index
        elif pattern_index > 0:
            pattern_index = lps[pattern_index - 1]
        else:
            text_index += 1
    return -1
```
