# 幅優先探索（BFS）コース設計票

作成・調査日: 2026-09-25。コースID: `course-algorithm-breadth-first-search-v1`。

## 選定理由

既存コースはバブルソート、選択ソート、二分探索、KMP法であり、配列と文字列を中心に扱っている。次はデータ同士の「つながり」という新しい対象へ進む。グラフ探索の入口として、近い場所から同心円状に広がるBFSは具体的に追いやすく、DFSの戻り処理やダイクストラ法の重み・優先度付きキューを先に要求しない。今後はBFS→DFS→ダイクストラ法の順で接続できる。

## 想定する学習者

大学生、Python経験半年〜2年を中心とするが、経験年数から理解を仮定しない。変数、文字列、リスト、辞書、if、for、while、関数、returnを一度学んだ経験を想定する。グラフ理論、頂点・辺、隣接リスト、キュー、deque、集合、計算量、再帰は未経験として扱う。英語変数名や図の規則を自力で推測させず、各画面に入力、現在地、発見済み、次に行う操作を示す。

## 前提知識

変数、文字列、リスト、辞書、if、for、while、簡単な関数とreturnを一度学んだ経験。辞書の`get`、`deque`、`popleft`、辞書を使った発見済み判定はコース内で具体例から導入する。集合、再帰、クラスは前提にしない。

## 与える体験と学習価値

開始地点を距離0とし、直接つながる場所を距離1、その隣を距離2として近い順に広げるイメージを作る。待ち行列は「左から取り出し、右へ追加」、距離辞書は「発見済みの印と距離の記録を兼ねる」という役割で理解する。完成コードを暗記せず、図の一手とPythonの行を対応づけ、最終的に`bfs_distances(graph, start)`を実装する。

## 解決する問題と扱う範囲

場所名をキー、直接つながる場所名のリストを値とする辞書を受け取り、開始地点から到達できる各場所までの最少の辺数を返す。すべての辺を同じ1歩として扱う。無向グラフを中心に説明し、到達できない場所は結果に含めない。

このコースでは、重み付き辺、経路そのものの復元、複数の連結成分をすべて巡回する処理、有向・無向の形式的定義、計算量証明、DFS、再帰、優先度付きキュー、ダイクストラ法は扱わない。

## 開始時点と完了時点

開始時点では、配列や辞書の基本構文を見た経験はあるが、グラフの図、つながり一覧、探索状態を対応づけられない。完了時には、現在の場所、待ち行列、発見済み、距離を読み取り、次に取り出す場所と新しく追加する場所を予測し、循環や複数経路を含むグラフでBFSを実装できる。

## 用語の導入順

場所とつながり→丸と線→グラフ→頂点と辺。直接つながる場所→つながり一覧→隣接リスト→`graph`、現在の場所→`node`、隣の場所→`neighbor`。近い順→距離ごとの層→幅優先探索→BFS。発見順に並べる→待ち行列→キュー→`deque`、左から取り出す→`popleft`、右へ追加→`append`。発見済みの記録と距離→`distances`。

- 配列の左右順からグラフへ対象が変わるため、Mission 2冒頭で「図の左右ではなく線を見る」という橋渡しを置く。

## 視線設計

グラフ表示の主強調は1ステップにつき一つとする。青は現在取り出した場所、紫は今見る隣、黄は発見済みで待機中、緑は確認済み、灰は未発見。色だけに頼らず日本語ラベルを併記する。辺は通常薄い灰色で、今回見る辺だけ紫にする。待ち行列はグラフの下へ置き、「次に取り出す側」と「追加する側」を表示する。距離は導入後だけノードの下へ表示する。コード接続前は英語変数やコード行を図へ出さない。

## 想定する誤解とフィードバック

- 図の近い位置を「隣」と誤認する: 線が直接ある場所だけを選ぶ練習を置く。
- 間接的に届く全場所を隣接リストに含める: `graph["A"]`だけを見る問題で区別する。
- 1本の道を奥へ進む: 距離1のBとCを両方先に処理する図を置く。
- `pop()`を使う: 待ち行列の左右と、近い順が崩れる例を示す。
- 発見済みを取り出し時に付ける: 2方向から同じEが見える例で、追加前に記録する理由を示す。
- 距離を同じ値のままコピーする: 辺を1本通るので+1と具体例で確認する。
- 到達不能頂点も返す: 開始地点からたどれる範囲だけを記録する問題を置く。

誤答1回目は現在地・待ち行列・発見済みのどこを見るかを示し、2回目以降は正しい状態と理由を表示する。図の色だけを答えにせず、問題文と日本語ラベルから判断できるようにする。

## 正解コード

```python
from collections import deque
def bfs_distances(graph, start):
    distances = {start: 0}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for neighbor in graph.get(node, []):
            if neighbor not in distances:
                distances[neighbor] = distances[node] + 1
                queue.append(neighbor)
    return distances
```
