# 単元画面のカード予告バッジ撤去（Issue #178）

目的: 単元画面のステージに付いていた知識カードの予告（レア度色のバッジ）を外す。最終確認日: 2026-11-06。

## 理由

- カードの付与は、フェーズ完了時のテーブル（スケジュール）による結果であり、学習周回ごとに変わるランダム要素を含む。ステージ上にレア度色のバッジを出すと「このステージでこのレア度のカードが手に入る」という約束に見える。
- aria-label にも「知識カードが手に入ることがあります」と入っており、読み上げでも予告になっていた。

## 実装

- `UnitOverview` から、ノード右上のカード形バッジ（レア度色＋星）と、aria-label の予告文を削除した。不要になった import（knowledgeCardTones、StarIcon）も外した。
- コンテンツ側の `cardRarity` 記録（どのステージの区切りでカード提示が起こりうるか）は、付与スケジュールの定義として残している。表示だけを止めた。
- ノードの状態表示（完了チェック、現在地の枠と「ここから始める」チップ）、旗、実績プレビューなど他の要素は変更していない。

## 検証

- `verify:unit-overview` の該当ピンを反転し、バッジ描画と予告文が残っていないこと、コンテンツの cardRarity 記録が維持されることを固定した。
- 全 verify・front の lint・typecheck・build が通過する。

## 確認方法

スクリーンショットは環境の都合で未取得のため、見え方はデプロイ後の実機確認に委ねる。

1. 単元画面の各ステージのノードに、カード形のバッジが付いていないことを確認する。
