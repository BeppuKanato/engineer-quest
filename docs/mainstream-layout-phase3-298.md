# 主流レイアウト移行（フェーズ3の3段組化）

- 目的: Issue #298 の移行シリーズ第3弾として、フェーズ3（動きの確認問題）を「中央スクロール＋下部固定ゾーン」の3段組にし、図（キャンバス）の高さをテキスト量から切り離す。
- 最終確認日: 2026-11-09
- 正本: Issue #298 と 2026-11-09 のユーザー承認。ベースは第2弾（フェーズ6の3段組化）のブランチ。

## 変更内容

- 全5単元の確認問題プレビュー（`*CheckPreview.tsx`）:
  - 問題文（キャプション）→状況文→指示→図→（二分探索のみ文章選択肢）を中央のスクロール領域に上から流す。中央寄せはもともと無く、構造だけを3段組に合わせた。
  - 図は固定高 `min(54dvh, 600px)` の枠（flex column）の中で表示する。キャンバスコンポーネント自体はフェーズ6と共有されるため変更せず、フェーズ3側の枠で高さを与える。従来は残り高さいっぱいに広がり、テキスト量で図が伸縮していた。
  - 再回答の注記・復習ボタン・「次の問題へ／結果を見る」・「もう一度解く」は下部の固定ゾーン（上罫で区切り）へ移動し、常時表示を保証する。ボタン行がもともと確保していた高さ（minHeight 44）はそのまま維持する。
- 通知（直前の回答）は第2弾で単元コンテナ側の固定ゾーンへ移済みのため、本弾では変更しない。単品表示時の通知は従来どおり中央領域の先頭に置く。

## 検証

- `verify:<unit>-check`（5単元）に固定高の枠・中央スクロール・下部固定ゾーンの契約を追加し全て通過。`verify:answer-feedback`、`verify:<unit>-unit`（5単元）も通過。
- #322 の状況文（situation）の表示、入力ロック、初回回答の記録など既存契約は不変。

## 未実施・留保
