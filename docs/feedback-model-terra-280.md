# フィードバック生成モデルの変更（Issue #280）

目的: フィードバック v1 の生成モデル既定値を `gpt-5.4-mini` から `gpt-6-1-luna` へ移行する。
最終確認日: 2026-11-07

## 変更内容

- `back/src/service/feedbackV1.engine.ts` の `getFeedbackModel` の既定値を `gpt-6-1-luna` に変更した。環境変数 `OPENAI_MODEL` が設定されている場合は、従来どおりそちらが優先される。
- reasoning effort は `medium` のまま。プロンプト文面・スキーマ・検証（`validateSelection`）は変更していないため、PROMPT_VERSION は据え置いた。生成ログ（`FeedbackV1Call`）にはモデル名が記録されるため、いつの生成がどのモデルかは追跡できる。
- `docs/feedback-v1-implementation.md`（2026-11-03 の実装報告）の「既定値 `gpt-5.4-mini`」の記述は実装時点の記録として残し、本書が現在の既定値を示す。

## 判断根拠

- `gpt-5.4-mini` は2026年3月発売で、現行は GPT-6.1 世代。OpenAI の廃止マッピングでも 5.4-mini の後継は 5.6/6.1 系のバランス帯に向けられている。
- 料金試算（2026-11-07、入力はプロンプト生成の実測：2段階合計 約4,200〜4,500字、出力は推論トークン込みで 1,500／3,000／6,000 トークンの3幅、¥155/$）：Terra（入力 $1・出力 $5／100万トークン）で1生成あたり中位 約3円。実験規模（12人×2単元×最大4提示＝96生成）でも約300円で、現行 5.4-mini（中位 約2.5円）との差は約15%増にとどまる。
- 本格的なモデル比較評価は行わない判断（ユーザー、2026-11-07）。まず現行運用の中で生成時間と品質を見て、必要なら effort 調整や再比較を別途検討する。

## 注意

- Cloud Run の環境変数 `OPENAI_MODEL` が設定されている場合、実効モデルはそちらで決まる。本変更は「環境変数が未設定の場合の既定値」であり、実稼働モデルの確認はデプロイ環境側で行う。
- コードのマージ・デプロイだけではシードや DB への適用は発生しない（本変更に DB 変更はない）。

## 検証

- back の `verify:feedback-v1`（エンジンの単体検証）を通した。モデル名は検証の対象外（モックコールを使用）だが、既定値の差し替えで型・参照が壊れていないことを CI の typecheck / verify:static で確認する。
