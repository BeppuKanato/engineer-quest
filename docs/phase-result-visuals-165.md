- 目的: フェーズ3・5の区切りリザルトとフェーズ6の結果画面を、テキスト中心から「見て分かる」形に組み替える。
- 適用範囲: `UnitResultScreen`（フェーズ3・5共有）、`BfsConsolidationPreview` の結果表示。状態: 実装記録。
- 最終確認日: 2026-11-06
- 正本: [Issue #165](https://github.com/BeppuKanato/engineer-quest/issues/165)、原案「2026-11-06_リザルト画面視覚強化-原案」（Drive の muse フォルダ）、[アプリUI/UX方針 §4・5](concept/app-ui-ux-guideline.md)、[教材指針](concept/learning-materials-guideline.md)、[紙吹雪 #144](phase-result-praise-144.md)。単元最終リザルトは #150 で別 PR とする（2 PR 分割は 2026-11-06 の決定）。

## 実装

### フェーズ3・5リザルト
- 独立した称賛文（`phaseResultPraise`）を削除し、`unitResult.presentation.ts` ごと除去した。事実文（全○問に正解しました（初回で○問正解））と #158 の紙吹雪・出現モーションだけを残す。称賛文は事実文と並ぶと文章だけが浮く、という実機フィードバックに基づく。
- 到達図 `BfsResultFigure` を追加した。単元共通の完成図1種（フェーズごとの出し分けはしない）で、BFS は全ノードに距離が入った最終状態のグラフ。描画は教材共通の `GraphDrawing` を静的（transition 0）に使い、ノードは学習中の状態色の完了グレーではなく達成を示す青（processing トーン）で塗る。距離バッジは白地に青字。
- 距離は `bfsGraph.ts` の `bfsDistancesFrom("A")` で正本グラフから導出する。距離の二重持ちをしないので、教材の距離と図がずれることはない。
- スコアのドット図示 `ResultScoreDots`（`features/learning/app/`、単元非依存）を追加した。総問題数分のドット（初回正解＝塗り、再挑戦で正解＝輪郭）で、summary の件数だけで描く集計表示。問題ごとの内訳データは保持していないため、内訳表示はしない。件数が不正・10問超では描かない。

### フェーズ6結果画面
- 「診断」の表記を廃し、画面名を「応用問題の結果」にした。関連する利用者向け表記も結果ベースへ統一した（セクションの aria-label、「結果を見る」ボタン、「結果には初回の回答を使います」の説明文、「論点ごとの結果」の aria-label）。内部の型名・コメント（診断型など）は変更していない。
- 冒頭に大きな分数（初回正解 ○／○ 問）と全体バーを置いた。見出し（キャプション）も「応用問題の結果」にし、分数はこの図示が担う。
- 論点タグを行カード `ResultTagRow`（`features/learning/app/`、単元非依存）で描く。正解は青いチェック＋「初回正解」。初回で届かなかった論点は、赤・❌・「初回不正解」の表記を使わず、中立の復習アイコン＋「復習で確認できます」とし、既存の復習ボタンをその行の主役にする。フェーズ6は正解しなくても進めるソフトゲートであり、結果は初回回答の記録として正直に出すが、失敗を強調しない。
- BFS の論点は各1問のためバーは出さない。論点が複数問を持つ単元では、行に分数（○/○ 問正解）と小バーを出す一般形にしてある。
- 判定（diagnoseAssessment：初回回答のみから導出、ソフトゲート）、復習先、保存・完了通知には触っていない。`data-diagnostic-tag` は `data-result-tag` に改名した（参照箇所は本画面のみ）。

## 検証

- `verify:bfs-unit`（拡張）: 称賛文モジュールの不在、到達図の距離導出（A0 B1 C1 D2 E2 F3）、ドットの状態列（first／retry）と不正件数での非表示、SSR での到達図・ドットの出現と初回正解数との一致、到達図が達成の青で描かれること（completed グレーを使わないこと）、フェーズ6の文言統一（「診断」の利用者向け表記の不在、「応用問題の結果」、`ResultTagRow` の使用、タグ行に「初回不正解」がないこと）を固定した。
- `verify:bfs-consolidation` を含む全 verify、front の lint・typecheck・build が通過する。

## 確認方法

対象 URL は http://localhost:3000/courses/roadmap/course-algorithm-breadth-first-search-v1/learn （ログインと進捗が必要）。スクリーンショットは環境の都合で未取得のため、見え方はデプロイ後の実機確認に委ねる。

1. フェーズ3（動きの確認問題）を解き切る。リザルトで、紙吹雪のあと独立した称賛文が出ないこと、完成したグラフ（青いノード＋距離バッジ）が出ること、初回正解の分だけドットが塗られることを確認する。
2. フェーズ5（コードの確認問題）でも同じ形のリザルトになることを確認する（図は単元共通で同じ）。
3. フェーズ6（応用問題）で、わざと1問間違えてから「結果を見る」まで進める。タイトルが「応用問題の結果」になっていること、大きな分数と全体バー、間違えた論点の行に赤や❌ではなく復習アイコンと「復習で確認できます」が出て、復習ボタンから基本例の復習が開けることを確認する。
4. 動きを減らす設定で、紙吹雪なし・静止した完成状態になることを確認する。
