# 棒倒し法 フェーズ6（応用問題）（Issue #211）

目的: 棒倒し法単元のフェーズ6を、異なる盤面での追跡・完成した迷路の性質・境界規則の理由・コード並べ替え（Parsons）の4問として実装し、初回回答による診断とフェーズ4への復習導線までを単品で操作できるようにする。設計は基準データ（docs/concept/wall-extension-unit-baseline.md §3、正本は未マージのため承認済み原本に従う）と教材指針フェーズ6に従う。最終確認日: 2026-11-06。本 PR は feat/wall-extension-phase5-210（PR #221）の上に積むスタック PR である。

## 実装内容

- `front/src/features/learning/wall-extension/consolidation/` に content / types / Preview / README.md を新設（構成は BFS フェーズ6に合わせた）。共通エンジンの diagnostic-check 形式で、設問ごとに操作指示・正誤の解説文・論点タグ・復習先を持つ。
  - Q1 `transfer-wall-target`（転移・グリッドタップ）: 転移用 7×7 の途中状態（2本目まで伸ばした盤面）を `wallExtensionMaze` の組み立てで作り、次に処理する柱 (2,4) と方向の指示「右」を示して、壁になるマスをタップで答える。正解 (3,4) は検証済みトレースの3本目から導出。回答対象はフェーズ3の問2と同じ考え方で、柱に隣接する未壁マス（(1,4) / (2,5) / (3,4)）に限る。盤面の表示とタップ回答はフェーズ3の `WallExtensionCheckCanvas` を流用。
  - Q2 `completed-maze-properties`（転移・選択）: 完成した迷路の性質を選ぶ。正解は「すべての通路がつながっていて、輪（ぐるりと回れる道）がない」。場面はフェーズ2の完成盤面を参照のまま使う。
  - Q3 `no-upward-extension`（推論可能なエッジケース・選択）: 一番上の段以外の柱が上に伸ばせない理由を選ぶ。正解は「上へ伸ばすと輪ができることがあるため」。場面はフェーズ2で柱 (2,4) を処理した盤面（上のマス (2,3) は壁でないことが見える）。復習先はフェーズ4の `y == 2` 条件のフレーム列（`if-first-row-2-4` → `else-branch-2-4` → `allowed-three-2-4`）で、else のフレームが理由をそのまま説明する。
  - Q4 `whole-code-order`（Parsons）: 参照コード（契約 wall-extension-v1）の21行すべてを並び替える。インデントは原文のまま提示し、妨害行は入れない。外周の4つの書き込みは互いに独立なため、ブロック内の順序だけ自由とし、それ以外は正解順に固定する（BFS の初期化2行の扱いと同じ考え方）。復習先はフェーズ4の全137フレーム。
  - 復習導線は全問フェーズ4のみで、新しい盤面の答え合わせは作らない（教材指針フェーズ6の割り切り仕様）。
  - `WallExtensionConsolidationPreview.tsx`: BFSフェーズ6と同じ診断型画面。初回正解スコア（アニメーション付き）と論点ごとの結果を表示し、届かなかった論点から該当設問の復習モーダル（フェーズ4の内容）を開ける。単品プレビュー `/learning-preview/wall-extension-consolidation` に登録。
- 共通化: BFS の `ParsonsBoard` のコード型を、行の意味IDと本文だけを使う構造型へ汎用化した（BFS 側の呼び出し・表示・操作は変更なし）。棒倒し法は同じ盤面に `wallExtensionCode` を渡して使う。
- ついでの修正: フェーズ3の `WallExtensionCheckCanvas` の読み上げラベルが「9×9」固定だったため、盤面の size から組み立てる形に変えた（Q1 の 7×7 で正しく読まれるようにする。9×9 の表示は従来どおり）。

## 検証

## 留保（判断が必要な点）

- Parsons の対象範囲は21行すべてとした。基準データは「参照コードの行を並び替える」とだけ定め、行の間引きを指定していない。BFS フェーズ6は自コードの全行が対象であり、教材指針ではフェーズ7のレベル4ヒントが「フェーズ6の Parsons と同じ盤面」を完成コードの構造として再利用する設計のため、一部だけに絞ると最終ヒントでコード全体を見せられなくなる。全行を採る代わりに、意味的に順序自由な外周の書き込み4行だけを順序自由として、行数ぶんの厳しさを緩和した。
- Q2 の選択肢は4つにした（BFS フェーズ6の選択問題は3つ）。Issue で指定された誤答例が3つあり（孤立した通路／輪がある／伸ばした壁が柱より多い）、いずれも独立検証で明確に誤りと示せるため、削らず全部を入れた。
- Q1 の設問文はフェーズ3の問2と同じ「壁になるマスはどれですか」とし、転移の文脈（7×7・処理中の柱・方向の指示）は場面と画面表示で示した。設問文だけで盤面の違いを説明する文にはしていない。
- 基準データの正本（docs/concept/wall-extension-unit-baseline.md）は PR #216 が未マージで本スタックに無いため、承認済み原本の §3 フェーズ6に従った（フェーズ3〜5の実施記録と同じ留保）。
