# 作る画面のカード上端揃え（Issue #184・レイアウト分）

目的: 作る画面（課題の実装画面）で、3カラム（要件／エディタ／プレビュー）のカードの上端が揃っていない問題を直す。最終確認日: 2026-11-06。

## 原因

- 3カラムのグリッド自体は上揃え（alignItems: start）だったが、要件カラムだけが先頭に「要件」の見出し（h5）を持ち、最初のカードがその分（見出し＋間隔で約42px）下がっていた。
- エディタとプレビューのカードは、タイトルをカード内に持つため、グリッドの上端から始まっていた。

## 実装

- 要件カラムの外付け見出しを外し、3カラムともグリッドの上端から最初のカードが始まる形にした。
- 要件の各カード（アコーディオン）には要件タイトルと種別チップがあり、カラム見出しが無くても判別に困らない。

## 範囲外（相談事項）

- エディタをフェーズ7（Monaco＋枠と見出しによる分離）に近づけるかは、本 Issue でも相談事項のまま。現状の作る画面のエディタも Monaco ではあるが、テーマや枠の扱いはフェーズ7と異なる。方針が決まれば別途対応する。

## 検証

- `verify:response-feedback` に、要件カラムが見出しで始まらないこと・グリッドの上揃えが維持されることを固定した。
- 全 verify・front の lint・typecheck・build が通過する。

## 確認方法

スクリーンショットは環境の都合で未取得のため、見え方はデプロイ後の実機確認に委ねる。

1. 作る画面の課題を開き、要件の最初のカード、エディタ、プレビューの上端が揃っていることを確認する。
