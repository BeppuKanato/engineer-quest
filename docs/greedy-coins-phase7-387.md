## 留保（判断した点）

- **視覚デバッグは未接続。** ボタン文言は基準データどおり「硬貨が選ばれる様子を見る」と定めたが、再生基盤（ハーネス拡張＋トレース変換）は次 Issue #388 の範囲のため、本 PR では接続していない。二分探索でもフェーズ7（#292）とトレース（#293）を分担したのと同じ切り分けで、実施記録とプレビュー画面のコメント、モジュールの README に未接続であることを明記した。
- **「全部書く」テンプレートは関数定義＋docstring の2行のみとした**（基準データ・タスクの指定どおり。`pass` は足さない。docstring のみの関数本体は Python として成立し、戻り値が無いため未着手で判定に失敗する）。docstring の文言は基準データに無いため、契約（引数 amount / coins、戻り値＝選んだ硬貨のリスト・選択順）から書いた。
