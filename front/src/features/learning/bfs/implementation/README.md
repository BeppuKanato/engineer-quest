# BFS フェーズ7（自分で実装）— プログラム形式

2026-11-25 の再設計（docs/redesign-overview-2026-11.md、Issue #513）に沿い、
フェーズ7を「関数を完成させる形」から「プログラムを書く形（標準入出力）」へ置き換えた。

- 学習者は標準入力から読み、標準出力へ出すプログラムを書く。関数名・変数名・書き方は固定しない。
- 入力：1行目が出発点、2行目以降が「場所 場所」のつながり。
  出力：登場する全場所についてアルファベット順に、出発点からの距離（到達不可は -1）を1行で出す。
- 判定は名前つきテスト5件＋自動チェック24件（種固定の乱数グラフ、期待値は参照実装で算出）。
  出力の形の問題（空・非数値・個数違い）は実行エラーと分けて知らせる。
- 書き方の量選択ゲート（自由／骨格／穴埋め）はプログラム形のテンプレートで存続。
  支援は段階式ヒント → 橋渡し（任意フェーズ6.5）→ お手本、のエスカレーション。
- 旧・関数形は `../implementation-legacy/` に保存してある（削除しない）。
