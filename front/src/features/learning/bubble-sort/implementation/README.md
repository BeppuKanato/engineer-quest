# バブルソート「自分で実装」

- 目的・適用範囲: Issue #233の自由記述課題 `bubble_sort(values)`（表示用2件＋判定用3件、全通過が完了条件のハードゲート）と段階式ヒント4段、D1専用の試しに実行を単品で操作する。状態: 現行。最終確認日: 2026-11-06。
- 正本: [バブルソート基準データ§2・§3](../../../../../../docs/concept/bubble-sort-unit-baseline.md)（未取り込みのため承認済み原本）、[教材指針](../../../../../../docs/concept/learning-materials-guideline.md)、[プレイヤーUI定義](../../../../../../docs/concept/learning-player-ui.md)。
- 実装・検証・指針との留保: [実施記録](../../../../../../docs/bubble-sort-phase7-233.md)。

`front`で`npm run dev`を実行して http://localhost:3000/learning-preview/bubble-sort-implementation を開く。認証・DBは不要。

| 内部ID（画面には出さない） | 表示 | 入力・期待値 |
| --- | --- | --- |
| D1 | 入力・期待する並び・実際の並び | [4, 2, 5, 1, 3] → [1, 2, 3, 4, 5]（主教材）。期待する並びはフェーズ2の完成ステップと同じ |
| D2 | 入力・期待する並び・実際の並び | [3, 1, 4, 2] → [1, 2, 3, 4]（応用問題の並び） |
| J1 | 種別・合否のみ | 重複あり [3, 1, 3, 2] → [1, 2, 3, 3] の完全一致 |
| J2 | 種別・合否のみ | 逆順 [5, 4, 3, 2, 1] → [1, 2, 3, 4, 5] の完全一致 |
| J3 | 種別・合否のみ | 並び済み [1, 2, 3, 4] → [1, 2, 3, 4] の完全一致 |

- 期待する並びは教材データの正本 `bubbleSort` の組み立て（参照コードと同じ手順の実行記録）から導き、フェーズ1〜6の教材とずらさない。判定は既存の教材テスト基盤（Worker 内の完全一致）で行う。引数を書き換えたかどうかは基盤が戻り値しか見ないため検出できない（基準データの「入力が変更されていないことも判定に含める」との関係は実施記録の留保に明記）。
- テスト結果は表示用だけ入力・期待する並び・実際の並びを示す。実際の並びは期待と違う場所をフォーカス青の枠で示し、件数を併記する。判定用の値・標準出力・生の例外は画面状態へ渡さない。
- 試しに実行は D1 だけを Worker を作り直して実行し、戻り値のリストを棒グラフで示す。通過数・実行回数・完了判定は変えない。
- ヒントは1→2→3→4の順に解放する。レベル3の骨格は参照コード（契約 bubble-sort-v1）の意味ID `for-pass`／`for-compare`／`if-larger` の3行を原文のまま示し、レベル4はフェーズ6の Parsons 盤面を同じ `ParsonsBoard` で練習モード表示する（採点しない）。
- 視覚デバッグ（Issue #234）: 「配列で動きを見る」で現在のコードを D1 でトレースし、`../trace/` のダイアログでフェーズ2と同じ配列キャンバスのステップ再生を表示する。取得中は編集・採点・試し実行・ヒントを無効にし、トレースは採点回数・ヒント回数を変えない。全通過後の完了表示からも同じコードを確認できる。詳細は `../trace/README.md`。

ファイル:

- `implementation.content.ts`: 課題文・テンプレート・5テスト・ヒント・表示文言と、フェーズ6 Parsons 設問／参照コード骨格行への参照。
- `implementation.ts`: テスト実行（1件ずつ、例外後も続行、判定用の秘匿）、エラー種別の分類、ヒント利用回数の記録、リストの値判定・描画用 Canvas 変換・期待との差分列挙、単元接続用の要約型。
- `BubbleSortImplementationPreview.tsx`: エディタ（ライトテーマ＋フォーカス色2px枠＋「Pythonコード」見出し）、テスト／コンソールのタブ、ヒント導線、全通過時の完了表示（紙吹雪と大きな描画チェック）。
- `ImplementationResults.tsx` / `ArrayOutput.tsx` / `FreeExecutionConsole.tsx` / `ImplementationHints.tsx` / `freeExecution.ts` / `editor.content.ts` / `editor.tokens.ts`: 結果表示、戻り値の配列表示、試しに実行のコンソール、ヒントダイアログ、D1専用フリー実行、画面文言、エディタ専用トークン。

検証: `npm run verify:bubble-sort-implementation`、`npm run verify:bubble-sort-trace`。単元フローへの接続・進捗保存は後続Issueの対象で、このモジュールは保存処理を持たない。
