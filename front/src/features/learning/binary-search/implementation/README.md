# 二分探索 フェーズ7（自分で実装）— プログラム形式

2026-11-25 の再設計（docs/redesign-overview-2026-11.md、Issue #513）に沿い、
フェーズ7を「関数を完成させる形」から「プログラムを書く形（標準入出力）」へ置き換えた。
契約は BFS・DFS と同じ。

- 学習者は標準入力から読み、標準出力へ出すプログラムを書く。関数名・変数名・書き方は固定しない。
- 入力：1行目が探す値、2行目が小さい順に並んだ数値（重複なし）。
  出力：探す値の位置（0から数える）1つ。なければ -1。
- 判定は名前つきテスト5件（基本／応用／探す値がない／先頭／末尾）＋自動チェック24件
  （種固定の乱数、ある場合とない場合の両方。期待値は並びの中の位置）。
- 旧・関数形は `../implementation-legacy/` に保存してある（削除しない）。
  単元結果画面は result の文言（title／closing）を本モジュールから参照する。
