# DFS フェーズ7（自分で実装）— プログラム形式

2026-11-25 の再設計（docs/redesign-overview-2026-11.md、Issue #513）に沿い、
フェーズ7を「関数を完成させる形」から「プログラムを書く形（標準入出力）」へ置き換えた。
契約は BFS（PR #529）と同じ。

- 学習者は標準入力から読み、標準出力へ出すプログラムを書く。関数名・変数名・書き方は固定しない。
- 入力：1行目が出発点、2行目以降が「場所 場所」のつながり（BFS と同じ形式）。
  出力：たどり着ける場所を、深さ優先で初めて訪れた順に1行で出す（たどり着けない場所は出さない）。
- 順番の約束はフェーズ4・5のコード契約 dfs-order-stack v1 のまま：
  スタックを使い、積むときに訪問済みにし、隣は逆順に積む。隣の並びは入力に現れた順。
- 判定は名前つきテスト5件＋自動チェック24件（種固定の乱数グラフ、期待値は参照実装で算出）。
  基本・応用の期待順は教材の正解順（A B D F E C／G H J K I L）と一致することを検証済み。
- 旧・関数形は `../implementation-legacy/` に保存してある（削除しない）。
