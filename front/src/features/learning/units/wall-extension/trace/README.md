# 棒倒し法 視覚的デバッグ（Issue #213）

- 目的: 現在の学習者コードを表示用D1（9×9、主教材の choices）で実行し、フェーズ2と同じ盤面で生成過程をステップ再生する。
- 適用範囲: トレース取得、盤面キャンバス変換、モーダル、フェーズ7画面との接続。状態: 現行。最終確認日: 2026-11-07。
- 正本: [Issue #213](https://github.com/BeppuKanato/engineer-quest/issues/213)、[棒倒し法基準データ §3 フェーズ7・§5](../../../../../../../docs/concept/wall-extension-unit-baseline.md)、[教材指針 §7-3](../../../../../../../docs/concept/learning-materials-guideline.md)、[BFS 視覚的デバッグ](../../bfs/trace/README.md)。

## 操作

`front/`で`npm run dev` → `http://localhost:3000/learning-preview/wall-extension-implementation` を開く。ログイン・バックエンド・DBは不要。

MonacoとPyodideの読込完了後、「盤面で動きを見る」を押す。取得中は編集・採点実行・試しに実行・ヒント・重複実行を無効にし、取得状態を表示する。モーダルは84vw × 84dvhで、既存LearningPlayerの再生・前後・シークを使う。図はフェーズ2のWallExtensionExecutionCanvasそのもの。下に観測行とsize・choices・壁の数を表示する。エディタのコード、採点結果、実行回数、ヒント回数はトレースでは変更しない。全テスト通過後は完了表示からも同じコードを確認できる。

## モジュールと安全なデータ経路

BFSトレース（Issue #76）と同じ構造に揃える。

- `public/python-trace-harness.mjs`（共通基盤への最小拡張）: locals検出に `grid` を追加した。`grid` という名前を優先し、なければ「奇数の一辺を持つ正方形の整数グリッド（3〜25）」という形で一意に検出する。候補が複数あれば推測せず曖昧として最終状態表示へ落とす。あわせて `size`（整数）と `choices`（整数列）を名前ベースで通過させ、戻り値がグリッドの場合も結果として受け付ける。BFS用の queue / distances 検出と結果の扱いは変更していない（盤面の戻り値を距離として扱わない分岐だけ明示した）。
- `acquireTrace.ts`: 前の判定用ケースを含むWorkerを破棄し、新しいWorkerへD1の関数名と引数だけを送る。tests・期待値・判定用引数は送らない。
- `convertTrace.ts`: イベント列の `grid` スナップショットから、壁集合が変わるたびにフェーズ2と同じ検証器（`validateWallExtensionExecutionCanvas`）を通る完全スナップショットを生成する。正しい迷路を再実行して差し替える処理はない。誤った盤面（余分な壁・欠けた壁）もそのまま表示する。
- `WallExtensionTraceDialog.tsx`: 既存LearningPlayerとWallExtensionExecutionCanvasを組み合わせるだけのモーダル。
- `trace.content.ts`: ボタン・状態・キャプションの文言。

トレースはD1だけ。標準出力・標準エラー、生の例外本文・トレースバック、任意のlocalsは返さない。例外は種別と学習者ソースの停止行だけを返す。イベント上限はBFSと同じ500件。

## 状態への対応付け（段階適用）

- 盤面が用意された（全0）→ 外周が壁になった → 柱が立った → 柱から1マス壁が伸びた、の変化を1コマずつにする。伸長コマは、壁になったマスに隣接する柱を処理中の柱（青）とし、伸びたマスをhighlightにする。隣接する柱が複数ある場合は、まだ伸ばしていない柱を優先する（生成順の推定であり、盤面そのものは実値どおり）。
- キャプションは変化の種類から機械生成する（外周／柱／柱から上・下・左・右へ伸長／その他の変化）。
- 途中から盤面として描けない状態（不揃いな行など）になった場合は、描けたところまで再生し「変換できない状態があるため、途中まで表示します。」と明示する。末尾が描ける状態に戻れば通常再生を続ける。
- `grid` のスナップショットが取れない構造（盤面を補助関数の中でだけ作る等）、変換できた状態がない場合、または形の候補が曖昧な場合は、停止位置と最終状態だけを表示する（教材指針 §7-3 の段階適用）。最終状態は戻り値のグリッドから作り、戻り値が盤面でなければ空の盤面に留める。

## 検証・対象外

`npm run verify:wall-extension-trace` は同じハーネスをpython3で実行し、参照コードの再生がフェーズ2の正準の壁列と一致すること、改名した盤面変数の形検出、途中エラーと停止行、補助関数内で作る盤面の最終状態表示、構文エラー、打ち切り、曖昧な候補、D1限定・新規Worker・キャンセルを確認する。

参照コード、テスト内容、4段階ヒントは変更しない。DB・進捗／ログ保存・フェーズ接続・単元コンテナは後続Issueの対象。
