# BFS 単元フロー（Issue #77）

- 目的: 単品ページで確認済みの BFS フェーズ1〜7を、1つの単元として通して学習できるよう接続する。
- 適用範囲: 単元内のフェーズ遷移、リザルト画面、単元内ナビゲーション。状態: 現行。最終確認日: 2026-11-05。
- 正本: [Issue #77](https://github.com/BeppuKanato/engineer-quest/issues/77)、[教材指針の遷移モデル](../../../../../../../docs/concept/learning-materials-guideline.md)、[学習フロー要約](../../../../../../../docs/concept/learning-materials-v2.md)

## 操作

`front/` で `npm ci` → `npm run dev`。起動したマシンで `http://localhost:3000/learning-preview/bfs-unit` を開く。ログイン・バックエンド・DB は不要。各フェーズの単品ページ（`bfs-motivation` など）も従来どおり開ける。

## 構成

- `BfsUnitPreview.tsx`: 単元の状態機械（現在の画面、到達した最先フェーズ、フェーズ別の到達状況）と単元ナビゲーション。
- `unit.content.ts`: フェーズの並びと遷移類型（choice / seamless / result / result-in-phase / final）、リザルト画面の文言。
- `UnitResultScreens.tsx`: フェーズ3・5の後のリザルト画面と、単元完了時の最終リザルト。
- `unit.types.ts`: 各フェーズから受け取る到達状況の型（型だけの共有）。

## 接続の仕組み

- 各フェーズの単品プレビューは、任意 props（`embedded`、`onComplete`、必要に応じて `onNext` / `nextLabel`）で単元に埋め込める。未指定なら単品ページとして従来どおり動く。
- フェーズ1→2 は意思確認の区切り：フェーズ1の最終場面のボタン（教材内のボタンそのもの）を押して進む。
- フェーズ2→3、4→5 はシームレス：共通プレイヤーの最終ステップにだけ出るアクションで次フェーズへ直結する。リザルト画面は挟まない。
- フェーズ3・5の後は単元側のリザルト画面（到達状況と次フェーズの予告）。フェーズ6は診断画面がリザルトを兼ね、診断内のボタンで次へ進む。フェーズ7の全テスト通過で最終リザルトを出す。
- 単品では進捗を画面内だけに持つ。アプリは任意propsで初期フェーズ・到達範囲・完了一覧・summary・下書き・完了保存・ログを接続できる。一度開いたフェーズはマウントしたまま隠すため、戻っても再生位置・回答・書いたコードが残る。フェーズ3・5は完了後に「もう一度解く」で解き直せる。
- 単元ナビゲーションでは、到達済みのフェーズまで自由に戻れる。未到達のフェーズへは進めない（前進は各フェーズの完了によってのみ解放される）。

## 対象外

アプリ本体への組み込み・進捗保存・下書き・ログはIssue #109の[実装報告](../../../../../../../docs/learning-screens-109.md)を参照する。今回、単元側は接続用の任意ポートと保存失敗時の再試行だけを追加した。プレイヤー UI 定義への適合（#83）も本モジュールでは扱わない。
